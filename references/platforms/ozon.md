# Ozon 套图子模块

> 本文是 Ozon 入口索引：只含平台定位、平台硬规则和路由。各版式/品类的完整规则以 `ozon/` 子目录为**唯一事实源**，做具体版式/品类时必读对应子文件。

## 平台定位

不要把 Ozon 当成"俄罗斯版 Amazon"。Ozon 更偏货架海报感：封面图默认有大字标题，副图和详情图根据类型承接卖点、细节、场景、尺寸、信息模块。

## 平台硬规则（大字 + 俄文）

- 封面、卖点图、细节图、信息图默认都要有大号俄文标题；主标题必须是画面最大文字，明确写"超大标题"。
- 主标题占画面宽度 35%-55% 或高度 12%-22%；1-2 行，每行 1-3 个俄文词，移动端商品卡也能读清。
- 功能卡文字也要大，不要做成小字说明。
- 提示词里必须写明：文字直接生成在图片里，不能后期添加。
- 图片里给买家看的文字必须是俄文；用户给中文卖点时，翻译并改写成自然简短的俄文（卖点 2-6 个词，说明模块 1 个短句），不要机器翻译腔。
- 字体用支持西里尔字母的无衬线字体：Golos Text、Inter、Roboto、Montserrat、Open Sans 或类似。
- 默认封面比例 `3:4`；详情页模块图 `3:4`；详情页长图 `750px` 宽。
- 服装类套图只要出现模特，就必须保持同一个模特：同一张脸、同一发型、同一身材比例、同一年龄段和肤色。
- 数字、尺寸、材质、数量、认证、品牌只能来自用户提供或图片可见信息，不能编造。
- EAC/GOST/认证标识只有用户确认产品真实具备时才能出现。
- 不出现价格、折扣、评分星星、评价数、收藏爱心、Ozon 标识、二维码、联系方式、水印、平台 UI、竞品名、假认证、假奖项。

## 使用流程（路由）

1. 整理产品信息（产品名、品类、规格、卖点、品牌、包装、目标人群、使用场景、参考图、张数、类型）。
2. 默认地区为俄罗斯，买家可见文案使用俄文。
3. 先读 `ozon/ozon-general-layouts.md`（全品类规范）。
4. 按任务类型读对应子文件（见路由表）。
5. 判断图片类型：`cover` / `gallery` / `rich-content` / `full-set`。
6. 结尾做简短合规检查。
