## 2. 主图相册 6 张结构

> **核心目的**：在 Amazon 搜索结果 / TikTok Shop 滑屏中，靠前 2 张主图抓点击，后 4 张快速回答 "长什么样 / 怎么搭 / 长度多少 / 细节如何"。

### 2.1 图 1 — 主图（白底正面全身 + 第一眼颜色冲击）
- **角色**：搜索结果主图，决定 CTR
- **构图**：纯白底或极浅灰底，模特正面全身站立，双脚微微外八（避免完全正面对称）；脸部只露下半张 + 锁骨 + V 领焦点
- **重点**：必须第一眼看到 **颜色 + 印花 + V 领 + 灯笼袖** 四个核心视觉锚点
- **配饰**：手提一只小包（米色 / 浅粉链条包），不抢衣服颜色
- **比例**：1:1（Amazon 搜索结果位）或 3:4（TikTok Shop 商品卡）
- **Prompt 关键**：
  - `white background, full-body front view, model standing straight, slight relaxed pose, holding small cream shoulder bag`
  - `green and white geometric floral print maxi dress, V-neck, lantern puff sleeves, drawstring waist, ruffle hem`
  - `clear color reproduction, dress occupies 70% of frame, no embedded text, no logo, no watermark`
- **反例**：不要全身黑底、不要杂志大片、不要大字卖点遮挡 V 领

### 2.2 图 2 — 场景正面全身（带度假配饰）
- **角色**：建立使用场景，海滨 / 度假 / 周末出行
- **构图**：浅灰白棚拍背景（仍是产品图基底），模特全身正面，加配饰堆砌：宽檐草帽 + 圆框墨镜 + 手提藤编包 + 罗马凉鞋
- **重点**：让买家 "脑补" 自己穿这套出门的画面
- **Prompt 关键**：
  - `light gray studio background, full-body front view, model wearing wide-brim straw sun hat, round-frame sunglasses, carrying woven straw tote bag, wearing strappy flat sandals`
  - `relaxed resort wear pose, natural daylight, soft shadows`
  - `no embedded text`
- **复用规则**：模特气质换为棕发 / 浅金发 / 亚麻色均可，**配饰组合（草帽 + 草编包 + 凉鞋）就是度假长裙的"视觉签名"，不要换掉**。

### 2.3 图 3 — 侧身全身（看版型 + 长度）
- **角色**：回答 "这个长度到我哪里 / 袖型是不是泡泡的 / 腰线落在哪"
- **构图**：侧面 90° 站立，重心放后腿，藤编包自然垂在身侧
- **重点**：**袖子的灯笼轮廓 + 抽绳腰 + 裙摆垂坠感** 在侧视最清晰
- **Prompt 关键**：
  - `side profile 90 degree view, full body, lantern sleeve silhouette visible, drawstring waist cinched at natural waist, ruffle hem falling to ankle`
  - `natural standing pose, weight on back leg, woven tote bag hanging by side`
  - `no embedded text`

### 2.4 图 4 — 背面全身（看后背 + 整体垂感）
- **角色**：回答 "后背长什么样 / 印花整体感 / 下摆走路是否拖沓"
- **构图**：背面站立，模特微微转头露侧脸（同系列图 5 的特写可呼应）
- **重点**：**后背中线 + 灯笼袖背面弧度 + 荷叶边下摆展开形态**
- **Prompt 关键**：
  - `back view full body, model slightly turning head to the side, lantern sleeves from back showing volume, tiered ruffle hem flaring out`
  - `wearing wide-brim straw hat, carrying woven tote bag`
  - `no embedded text`

### 2.5 图 5 — 半身 / 局部特写（强调 V 领 + 灯笼袖）
- **角色**：让买家凑近看领口、袖型、印花纹理
- **构图**：从头顶到腰下，**戴草帽 + 墨镜**，**V 领锁骨线 + 灯笼袖膨胀感** 同时进入画面
- **重点**：这是 "细节信赖图"，让买家确认 "印花不是印糊的 / 袖口走线干净 / 领口是 V 不是圆"
- **Prompt 关键**：
  - `medium close-up from top of hat to waist, V-neckline clearly visible with collarbone, lantern puff sleeve showing balloon volume, geometric floral print detail`
  - `wearing straw hat and round sunglasses, warm natural light`
  - `no embedded text`
- **复用规则**：当袖型 / 领口 / 印花纹理是这款的核心卖点时，**这张必须有**，不能省。

### 2.6 图 6 — 场景正面备选（与图 2 区别：配饰更少 / 半身为主）
- **角色**：图 2 的 "轻量备选"，证明衣服脱离度假配饰也能日常穿
- **构图**：浅灰背景，正面全身，**只戴草帽 + 墨镜，无草编包**，把视觉重量让给衣服
- **Prompt 关键**：
  - `front view full body, light gray background, wide-brim straw hat, round sunglasses, no bag, natural relaxed pose`
  - `showing how dress looks without extra resort accessories, everyday wear look`
  - `no embedded text`

## 3. 详情页 6 张结构

> **核心目的**：在详情页 / 滑动浏览中，回答 "尺码 / 主题场景 / 卖点 / 细节 / 多色 / 尺码图" 六个买家最关心的问题。
> **关键发现：这张套图完全没走"参数解释型"路线，而是"主题场景 + 文字大标题 + 真实 UGC"的混合路线**。对美式度假长裙非常有效，比硬塞尺码表 / 材质说明更有说服力。

### 3.1 图 7 — 尺码表（US ANRABESS WOMEN DRESS）
- **角色**：基本款尺码表，必须给
- **结构**：
  - 上半 = **Product Measurements**（衣服本身的平铺尺寸）：Brand Size / US Size / Waist / Sleeve Length / Length
  - 下半 = **Body Measurements**（买家身材参考）：Brand Size / US Size / Bust / Waist / Hip
- **关键点**：
  - 用 inch 不用 cm（美式市场）
  - 大字号、粗网格、宽行距，**不堆小字**
  - 单位写 `(in)` 而不是 `(inch)`
  - 不写尺码建议 / 不写模特身高体重（这是反例）
- **Prompt 关键**：
  - `clean ecommerce size chart, large bold sans-serif typography, white background, dark gray text`
  - `two tables: "US ANRABESS WOMEN DRESS PRODUCT MEASUREMENTS" with columns Brand Size / US Size / Waist (in) / Sleeve Length (in) / Length (in); and "US ANRABESS WOMEN DRESS BODY MEASUREMENTS" with columns Brand Size / US Size / Bust (in) / Waist (in) / Hip (in)`
  - `5 rows for S M L XL XXL, clear readable text, correctly spelled, no random letters`
- **数据实例**（参考用，复用时必须用真实数据）：
  - Product: S(4-6) 37.4/18.9/50 · M(8-10) 39.4/19.3/50.6 · L(12-14) 41.7/19.7/51.2 · XL(16-18) 44.9/20.1/51.8 · XXL(20-22) 48/20.5/52.4
  - Body: S(4-6) 33.9-35/26.4-27.6/37-38.2 · M(8-10) 35.8-37/28.4-29.5/40-40.2 · L(12-14) 38.2-39.4/30.7-31.9/41.3-42.5 · XL(16-18) 41.3-42.5/33.9-35/44.5-45.7 · XXL(20-22) 44.5-45.7/37-38.2/47.6-48.8

### 3.2 图 8 — 主推卖点大图（Maxi Dress / Puff Sleeve）
- **角色**：详情页第一张视觉重击，卖点 + 主题场景
- **结构**：
  - 横向 4-5 联拼图，海边咖啡厅露台场景（白椅 + 蓝色海面）
  - 居中叠加一个半透明白色矩形 callout
  - 文字层级：**手写体主标题 `Maxi Dress`**（最大，米白底）→ **粗体大写副标题 `PUFF SLEEVE`**（橙红色，最醒目）→ **小写细体小标题 `WOMEN BOHO MAXI DRESSES` / `2025 V NECK CASUAL LONG DRESS`**
- **关键点**：
  - 字体组合 = **手写体（情绪） + 粗体大写（卖点） + 细体小写（属性）**，**不要三段都用同一种字体**
  - 颜色：橙红 / 砖红 是美式度假风的"安全色"，不刺眼也不土
  - 背景不要太花：浅蓝海 + 白椅 = 干净不抢衣服
- **Prompt 关键**：
  - `coastal cafe terrace scene, white bistro chairs, blue Mediterranean sea in background, 4-panel horizontal collage of same model in blue and white geometric print maxi dress`
  - `centered white semi-transparent text callout, large handwritten script "Maxi Dress" in cream/white, bold uppercase serif "PUFF SLEEVE" in terracotta orange, small sans-serif "WOMEN BOHO MAXI DRESSES" and "2025 V NECK CASUAL LONG DRESS" below`
  - `clear readable English text, minimal text, correctly spelled, no random letters, no logo`

### 3.3 图 9 — 主题副场景（Trendy Long Flowy Dress / Relaxed Fit）
- **角色**：补一张"轻松穿出门"的生活方式图
- **结构**：
  - 横向 4 联拼图，**白墙 + 绿植 + 鹅卵石小径**的安静花园 / 民宿场景
  - **左上角**：黑色加粗标题 `Trendy Long Flowy Dress`
  - **右下角**：手写体橙色 `Relaxed Fit`（可看作 "软卖点标签"）
- **关键点**：
  - 颜色替换：**紫白印花**版本（与主图绿白区分），证明同款多色
  - 场景从 "海边咖啡" 切到 "民宿花园"，覆盖不同买家想象
  - 圆角白边框 / 不规则裁切 = 美式生活杂志感
- **Prompt 关键**：
  - `white Mediterranean villa courtyard with green tropical plants and stone path, 4-panel horizontal collage of model in purple and white geometric print maxi dress`
  - `top left bold black sans-serif "Trendy Long Flowy Dress", bottom right handwritten orange script "Relaxed Fit"`
  - `clear readable English text, minimal text, correctly spelled`

### 3.4 图 10 — 细节 callout 三圆图（V Neck / Lantern Sleeve / Floral Print Design）
- **角色**：**直接对应主图 #5 的局部特写，把"袖口、领口、印花"三点放大解释**
- **结构**：
  - 海边沙滩背景，左右各 1 张全身模特（绿白印花）
  - 中间 3 个圆形 callout 框，**从下到上**分别是：
    1. **Floral Print Design**（印花特写）
    2. **Lantern Sleeve**（灯笼袖特写）
    3. **V Neck**（V 领特写）
  - 圆框之间用**手绘虚线箭头**连接
- **关键点**：
  - **圆框 + 手绘虚线箭头** = 这套图最值得复用的视觉签名
  - callout 框外有黑色细线边框 + 圆角
  - 文字是**黑色无衬线 + 小写**，不抢圆框
  - 顺序 = 从下到上 = 印花 → 袖 → 领，**先视觉后版型**
- **Prompt 关键**：
  - `beach scene with turquoise sea, model in green and white print maxi dress, three circular callout insets connected by hand-drawn dashed arrows`
  - `bottom circle: close-up of geometric floral print with label "Floral Print Design"; middle circle: lantern sleeve close-up with label "Lantern Sleeve"; top circle: V-neck close-up with label "V Neck"`
  - `clear readable English text, minimal text, correctly spelled, black sans-serif labels`

### 3.5 图 11 — UGC 多色买家秀
- **角色**：证明 "我买回来穿出来就是这样"，同时**展示同款多色**
- **结构**：
  - 横向 4 联拼图，**真实 UGC 风**（不棚拍、不杂志）
  - 4 个真人买家（不同身材 / 不同场景）：
    1. 紫白印花 + 卧室 + 高跟凉鞋
    2. 豹纹印花 + 玄关镜自拍
    3. 蓝白印花 + 客厅 + 高跟凉鞋
    4. 蓝白印花 + 客厅 + 平底鞋
  - **左下角**：手写体小标签 `Ruffle A-Line Hem`
  - **右下角**：大号米色大写 `LONG DRESSES`
- **关键点**：
  - **必须是真实 UGC 风格**（手机随手拍、家居背景、买家本人），**不要棚拍**
  - 4 张拼接，**尺寸略有差异、有白边框胶片感** = 美式 Instagram collage 视觉
  - 多色展示 = 紫 / 豹纹 / 蓝，**绿白是主图色，详情页用其他色补足**
- **Prompt 关键**：
  - `4-panel UGC buyer photo collage, authentic phone camera quality, slight color variation between panels, white Polaroid-style borders`
  - `buyer 1: purple print dress in bedroom; buyer 2: leopard print dress in entryway mirror selfie; buyer 3 and 4: blue print dress in living room with different angles`
  - `bottom left handwritten "Ruffle A-Line Hem", bottom right large cream sans-serif "LONG DRESSES"`
  - `no embedded text in buyer photos, text only in overlay area`

### 3.6 图 12 — 尺码图（带模特图示的 SIZE CHART IN）
- **角色**：比图 7 更视觉化的"尺码图"，**模特身上直接画虚线标尺寸**
- **结构**：
  - 左侧：模特图（红色印花版），身上叠加**灰色虚线 + 文字标签**：
    - `Waist`（腰）
    - `Sleeve`（袖）
    - `Length`（长）
  - 右侧上半：**Product measurements** 表（S/M/L/XL/XXL × Waist / Sleeve / Length）
  - 右侧下半：**Body measurements** 表（S/M/L/XL/XXL × Bust / Waist / Hips）
  - 底部：洗护小字 `Wash - Hand wash/Do Not Bleach/Dry Flat/Do not iron.`
  - 最底部：两个属性条 `STRETCH: Medium` / `FIT TYPE: Loose`
- **关键点**：
  - **单位写 `(IN)` 大写，不写 `inch`**
  - 大字号、粗网格，**不堆小字**
  - 模特图上**用虚线 + 大箭头**直接标位置，比纯表格直观
  - 洗护信息可以保留，但**只用一行 4 个短动作**，不要长段
- **Prompt 关键**：
  - `clean ecommerce size guide with model diagram, left side model in red print dress with dashed gray lines and labels "Waist" / "Sleeve" / "Length"`
  - `right side two tables: "Product measurements" (SIZE(US) / WAIST / SLEEVE / LENGTH) and "Body measurements" (SIZE(US) / BUST / WAIST / HIPS)`
  - `bottom: "Wash - Hand wash/Do Not Bleach/Dry Flat/Do not iron.", two attribute rows "STRETCH: Non/Slight/Medium/High" with Medium highlighted, and "FIT TYPE: Skinny/Slim/Regular/Loose/Oversized" with Loose highlighted`
  - `clear readable English text, minimal text, correctly spelled`

## 5. 通用沉淀结论

### 5.1 套图结构
- **6+6 是美式长裙的标准套数**，不要自己发散到 5+8 或 8+8。
- 主图 6 张的顺序 = **正 → 场景正 → 侧 → 背 → 局部 → 场景正备选**，**不能乱**。
- 详情页 6 张的顺序 = **尺码 → 主推 → 副推 → 细节 → UGC → 尺码图**，**不能乱**。
- 6 张详情页里，**至少 2 张用主题大场景（海边 / 花园 / 街拍）**，不要全塞白底参数图。

### 5.2 构图原则
- **主图 1 必须白底或极浅灰底**，**不要直接上场景**（CTR 决定一切）
- 度假风的"视觉签名配饰" = **草帽 + 草编包 + 凉鞋**，主图 2/3/4 至少出现 2 个
- 半身特写（主图 5）必须能同时看到 **V 领 + 灯笼袖**，不能只特写领口
- 背面图（主图 4）**一定要模特微转头**，纯背面没人看
- 6 张主图里**至少有 2 张不戴帽子**，避免买家以为"这是草帽展示不是衣服展示"

### 5.3 文案规则
- **美式长裙详情页的字体三层 = 手写体（情绪） + 粗体大写（卖点） + 细体小写（属性）**
- 颜色首选 **橙红 / 砖红** = 度假风安全色；不要用纯黑、纯红
- callout 标签（细节图）**用黑色无衬线小写**，不要塞大字
- 尺码表 / 尺码图 = **inch 单位 + 5 行 S-XXL + 大字号粗网格**，不堆小字
- 洗护信息 = **一行 4 个短动作**：`Hand wash / Do Not Bleach / Dry Flat / Do not iron`，不要长段

### 5.4 视觉签名
- **3 圆框 + 手绘虚线箭头** = 细节 callout 图的标准签名
- **半透明白色 callout 矩形** = 主题大场景主推图的标准签名
- **胶片白边框 + 略微歪斜的拼接** = UGC 多色图的标准签名
- **模特图 + 灰色虚线标注** = 尺码图的标准签名

### 5.5 多色策略
- 主图固定展示 1 个色（一般是主推色 / 第一眼色）
- 详情页副推图（详情 3）和 UGC 多色图（详情 5）**必须展示至少 2-3 个同款其他色**
- 同款多色不要写颜色名，**靠印花本身让买家自己认**

### 5.6 风险点 / 反例
- ❌ 模特图里有真实品牌名、logo、平台 UI、二维码、联系方式 — 全部去掉
- ❌ 写 `#1 / Best / Guaranteed / 100%` 等绝对化词
- ❌ 主图 1 用大字卖点遮挡 V 领
- ❌ 详情页全是白底参数图，没有一张主题大场景
- ❌ UGC 图里用棚拍精修图代替真实买家秀
- ❌ 尺码表用 cm 单位（美式市场必须 inch）
- ❌ 模特身上只穿高跟鞋 / 完全不合适场景的鞋子
- ❌ 把"ANRABESS"或"Amazon"等品牌名 / 平台名写进新生成的 prompt（除非用户明确要求保留）

### 5.7 复用 checklist
- [ ] 是否确认了目标市场（US / EU / UK / 巴西 / 墨西哥 / 东南亚）？
- [ ] 是否把绿白替换成了真实产品的主推色 / 印花？
- [ ] 主图 1 是否白底、无字、露 V 领 + 灯笼袖？
- [ ] 主图 2-4 是否带草帽 / 草编包 / 凉鞋中至少 2 个？
- [ ] 主图 5 是否能同时看到 V 领 + 灯笼袖？
- [ ] 主图 6 是否比主图 2 配饰更少？
- [ ] 详情 1 尺码表是否用 inch + 5 行 S-XXL？
- [ ] 详情 2 主推大图是否用字体三层（手写 + 大写 + 细体）？
- [ ] 详情 3 副推图是否用同款多色？
- [ ] 详情 4 细节图是否用 3 圆框 + 手绘虚线箭头？
- [ ] 详情 5 UGC 图是否用手机质感 + 胶片边框？
- [ ] 详情 6 尺码图是否用大写 `(IN)` + 模特虚线标注？
- [ ] 所有信息图的文字是否要求 `clear readable English text, minimal text, correctly spelled, no random letters`？
- [ ] 是否过滤掉所有品牌名 / logo / 平台 UI / 二维码？
