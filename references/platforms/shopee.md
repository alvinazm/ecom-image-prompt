# Shopee（虾皮）套图子模块

> 本平台规则**全部内联于本文件**（无子目录），本文件即唯一事实源。这是本 skill **新增**的平台模块（补齐原套图 skill 缺失的 Shopee 入口）。如与 `social-image-prompt-generator-overseas` 等通用海外 skill 冲突，以 Shopee 规则为准。

## 核心定位

Shopee 不是"东南亚版 Amazon"。Shopee 主图有更重的"东南亚货架海报感"：大字号、轻场景、本地语言、短卖点；详情页可以带短文案但要简洁。Shopee 用户对"价格感、活动感、本地化语言"敏感度高。

## Shopee 主图硬规则

- **比例**：默认 `1:1`（商品卡），但平台商品卡也支持 `3:4`；用户未指定时默认 `1:1`。
- **背景**：白底优先（main image），但允许带浅色背景和主图大字。
- **文字**：允许在主图内直接带大号本地语言短标题（区别于 Amazon）；主标题可占画面 30%-45%。
- **模特**：本地化模特气质和场景；避免欧式过浓。
- **价格/活动元素**：Shopee 允许在主图带价格、活动标签、限时优惠等运营元素（区别于 Amazon）— 但需用户给具体数字，禁止 AI 编造。
- **平台 UI 元素**：禁止 Shopee logo、店铺名、收藏爱心、平台标识等。

## 主图 vs 副图 vs 详情页 区别

| 类型 | 业务位置 | 默认数量 | 推荐比例 | 核心任务 |
|---|---|---|---|---|
| 主图 | 搜索结果 / 推荐流 | 1 | 1:1 | 抢点击 + 强本地化 |
| 副图 | 商品相册第 2-N 张 | 4-6 | 1:1 / 3:4 | 功能 / 细节 / 场景 / 规格 |
| 详情页 | 商品详情长图 | 6-8 段 | 3:4 / 9:16 | 转化 + 信任 |
| SKU 图 | 颜色/规格 | 每个 2 张 | 1:1 | 白底 + 模特 |
| 活动海报 | 大促 / 节日 | 1-4 | 1:1 / 3:4 / 9:16 | 主题 + 价格感 |

## 工作流

1. **识别站点**：9 站点之一；否则按用户实际运营的站点。
2. **识别品类**：服装 / 3C / 家居 / 美妆 / 母婴 / 食品 / 配饰 等。
3. **本地化**：模特、场景、单位制、文案语言、节日匹配目标市场。
4. **风格确认**：未给时给 4-6 个可选风格方向。
5. **输出确认稿**：每张图按平台规则出确认稿。
6. **交付提示词 + 文案**：本 skill 只出可复制提示词，不执行生图；用户确认后交付，由用户自行粘贴到生图工具生成。

## 默认主图 SOP

主图必须做到两件事：
1. 一眼看懂商品是什么。
2. 一眼看懂它的主要优势 + 价格感 / 活动感。

主图提示词要包含：
- 产品完整描述（品类、颜色、材质、结构、细节）
- 卖点：1-2 个最核心的
- 场景：东南亚本地日常场景
- 构图：1:1，主体占画面 65%-80%
- 文案：可加本地语言大号短标题（如 `Diskon Hari Ini`、`฿199 Only`、`Free Shipping`）— 但价格必须用户给
- 模特：本地化模特气质、肤色、场景

## 副图 SOP

每张只讲一个信息点：
1. 角度变化（侧面/背面/3/4）
2. 细节特写（面料/材质/接口）
3. 功能演示（使用/收纳/安装）
4. 场景图（本地生活/出行/工作）
5. 规格/参数图
6. SKU 多色图

## 详情页 SOP

按购买决策顺序：
1. 首屏利益点（一句话）
2. 痛点场景
3. 功能说明
4. 材质/面料
5. 版型/工艺
6. 规格/尺码
7. 场景收尾

详情页必须先定义"连续详情页视觉系统"，再逐张输出。

## SKU 图 SOP

每个 SKU 2 张：
1. 白底商品图（1:1，无字）
2. 模特上身图或场景图

## 活动海报 SOP

启动时询问：活动主题 / 输出数量和比例 / 是否复刻参考图风格。

节日参考：
- SG/MY/PH/ID/TH/VN：开斋节 / 农历新年 / 双 9 大促 / 双 12 / 12.12 Birthday Sale / 斋月 / 泼水节 / 圣诞
- TW：双 11 / 双 12 / 母亲节 / 春节
- BR/MX：Black Friday / Día de las Madres / Navidad

规则：
- 必须有活动主题、产品焦点、批发氛围
- 价格、优惠、券、赠品、限时信息必须来自用户；未提供时不要编造
- 可以直接生成本地语言活动标题和短利益点
- 避免绝对化用语，例如"全网最低""第一""最好"

## 合规底线

- 主图：白底或浅色背景，无价格欺骗，无夸大宣传。
- 副图 / 详情页：可有场景和文字，但不能做虚假、无法证明、医疗化、竞品对比、促销式 claim。
- 不编造价格、起订量、库存、认证、销量。
- 不生成 Shopee logo、店铺名、收藏爱心、平台 UI。
- 穆斯林国家（ID/MY）避开宗教敏感元素；TH 避开王室符号；VN 避免政治敏感。
- 不使用未授权品牌 logo、二维码、联系方式、车牌。
