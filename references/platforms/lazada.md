# Lazada 套图子模块

> 本平台规则**全部内联于本文件**（无子目录），本文件即唯一事实源。这是本 skill **新增**的平台模块（补齐原套图 skill 缺失的 Lazada 入口）。

## 核心定位

Lazada 是阿里巴巴旗下东南亚电商平台。比 Shopee 更偏正式、品牌感、参数感，主图风格更接近"货架电商"。Lazada 用户对品牌、参数、品质信任更敏感，对夸张价格感相对克制。

## 主图硬规则

- **比例**：默认 `1:1`（商品卡）。
- **背景**：白底优先（main image），但允许带浅色背景。
- **文字**：可有本地语言大号短标题（区别于 Amazon 但比 Shopee 克制）；主标题占画面 25%-40%。
- **模特**：本地化模特气质，避免欧式过浓。
- **价格/活动元素**：可有"折扣"或"Free Shipping"等运营元素，但需用户给具体数字。
- **平台 UI 元素**：禁止 Lazada logo、店铺名、收藏爱心、平台标识等。

## 主图 SOP

主图必须做到两件事：
1. 一眼看懂商品是什么。
2. 一眼看懂它的主要优势 + 品牌 / 参数感。

主图提示词要包含：
- 产品完整描述（品类、颜色、材质、结构、细节）
- 卖点：1-2 个最核心的
- 场景：东南亚本地日常场景（偏正式 / 通勤 / 居家）
- 构图：1:1，主体占画面 65%-80%
- 文案：可加本地语言大号短标题（如 `Free Shipping`、`Brand New`）— 但价格必须用户给

## 副图 SOP

每张只讲一个信息点：
1. 角度变化（侧面/背面/3/4）
2. 细节特写（面料/材质/接口）
3. 功能演示
4. 场景图
5. 规格/参数图
6. SKU 多色图

## 详情页 SOP

按购买决策顺序：
1. 首屏利益点
2. 痛点场景
3. 功能说明
4. 材质/参数
5. 工艺/规格
6. 场景收尾
7. 信任收尾（品牌 / 售后）

详情页必须先定义"连续详情页视觉系统"，再逐张输出。

## 合规底线

- 主图：白底或浅色背景，无价格欺骗，无夸大宣传。
- 副图 / 详情页：可有场景和文字，但不能做虚假、无法证明、医疗化、竞品对比、促销式 claim。
- 不编造价格、起订量、库存、认证、销量。
- 不生成 Lazada logo、店铺名、收藏爱心、平台 UI。
- 穆斯林国家（ID/MY）避开宗教敏感元素；TH 避开王室符号；VN 避免政治敏感。
- 不使用未授权品牌 logo、二维码、联系方式、车牌。
