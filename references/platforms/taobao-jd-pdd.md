# 淘宝/京东/拼多多 套图子模块

> 本文是入口索引：只含平台定位、平台硬规则和路由。类目完整规则以 `taobao-jd-pdd/` 子目录为**唯一事实源**。

## 平台定位

中国电商商业化素材链路：主图/副图（点击率 + 商品相册承接）→ 详情页（转化、信任、购买理由）→ SKU 图（颜色/规格选择）→ 活动海报（节日、大促、店铺活动、投放）。除非用户明确只要其中一类，否则默认启动完整 SOP。

## 平台差异（先定位平台，再进规则）

- **京东**：白底图、规范陈列、参数感和商业化表达，画面通常更干净、更专业。
- **天猫**：白底图、品牌感、规范化和商业化表达，整体比淘宝更稳、更整齐。
- **淘宝**：更偏 UGC 感、真实感、场景感和转化。
- **拼多多**：更偏性价比、活动感、夸张卖点、"限时/特价"表达。

## 平台硬规则

- 先判断图片角色，再识别产品（见 `_sop-common.md` 第 0 步）。
- 服装类主图/SKU 图优先保证商品版型、颜色、材质、穿着效果，不让文字遮挡产品。
- 套图和详情页必须优先保证"连贯性"：详情页先定义一套连续视觉系统（统一背景/主色/版式组件/产品锚点/道具光影/文字气质/叙事顺序），再逐张输出，像同一条详情长图的连续分屏。
- 用户要求"直接生成"时，提示词里直接给出完整画面和文字排版（不留白、不做后期排版），但仍只输出提示词，不执行生图。
- 不编造数据；避免绝对化用语，例如"全网最低""第一""最好"。

## 默认 SOP 要点（平台通用，类目特化见子文件）

### 主图/副图

- 主图：1:1，主体占画面 65%-80%，服装主图默认无文字；活动主图可加短标题。
- 副图：1:1 / 3:4，每张只讲一个信息点。常见顺序：核心卖点补充 → 细节/材质 → 使用场景 → 规格/参数 → SKU/颜色。

### 详情页

按购买决策顺序组织 1-7 图：首屏利益点 → 场景痛点 → 功能说明 → 面料细节 → 版型细节 → 尺码参数 → 场景收尾。

### SKU 图

每个 SKU 默认 2 张：白底商品图（看颜色、版型、细节）+ 模特上身图（看穿着效果、长度、廓形、搭配感）。颜色名要写进提示词，并解释成具体色相，例如"阳光橙=明亮橙色""霜紫灰=低饱和薰衣草灰紫"。

### 活动海报

启动时询问或提取：活动主题 / 输出数量和比例 / 是否复刻参考图风格。价格、优惠、赠品必须来自用户，不编造。避免绝对化用语。

## 套图风格确认

未给风格时按类目给 4-6 个建议方向（化妆品默认包装色系高级棚拍风，口腔护理默认医疗信任功效风，详见子文件）。服装/户外类可用：清爽白底通勤风 / 轻户外旅行风 / 韩系温柔穿搭风 / 高级极简棚拍风 / 活泼多巴胺风 / 节日活动海报风。
