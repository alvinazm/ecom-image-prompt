# 通用套图 SOP（跨平台共用）

这是各平台子模块都会引用的公共 SOP。所有平台子模块默认遵循这里的规则，再叠加各自的平台特性。

## 通用原则

1. **先识别图片角色，再识别产品**：上传多张图时，必须先分清产品图 / 参考图 / 竞品图 / 参数图 / 工厂图；只有用户明确说"参考这个"时，才拆解参考图反推风格。
2. **客户图不能照抄**：下载来的图只能用于风格、构图、信息层级参考；不得照抄原商品主体、品牌、文案、价格、活动信息、未经授权 logo。
3. **默认直接出完整成图**：用户未明确说"留白 / 无字 / 后期排版"时，详情图、参数图、活动图、Pin 默认让 AI 生成完整画面和文字排版；主图 / 纯场景图 / UGC 自然图默认无字。
4. **不编造数据**：价格、优惠、起订量、库存、认证、销量、成分百分比、防晒指数 等一律不得凭空写，除非用户给数据。
5. **连贯性优先**：同一套图沿用背景、主色、字体、卡片、图标、道具、光影和产品锚点，详情页必须像一条长图的连续分屏，而不是各自独立的 6 张海报。
6. **合规底线**：禁止 `best / #1 / 100% / guaranteed / world no.1` 等绝对化表达；禁止平台 UI（价格、星星、收藏、平台 logo、评分）；禁止未经授权品牌 logo、二维码、联系方式、车牌、平台 UI。
7. **本地化**：图片内文字、模特气质、场景、单位制 必须符合目标市场，巴西葡语 / 俄语西里尔 / 韩文 Hangul / 东南亚本地语言；不确定时先问用户。

## 启动流程（所有平台共用）

### 第 0 步：判断图片角色

当用户上传多张图或说明"这是客户要求的图 / 下载的图 / 竞品图 / 参考图 / 想做成这种感觉"时，先分角色：

- **产品图**：客户自己的商品，用来锁定真实产品外观。
- **参考图**：客户喜欢的风格、构图、氛围、排版。
- **竞品图**：同类商品的卖点表达、详情结构、功能呈现。
- **规格图**：尺码、参数、颜色、包装 等信息来源。
- **工厂图 / 实力图**（1688 场景）：工厂、仓库、质检、发货、定制能力来源。

如果角色不清楚，先问一句：
> 这几张里哪张是客户自己的产品图，哪几张是参考/竞品/工厂/参数图？

### 第 1 步：识别产品特征

如果用户提供产品图或文字描述，先做：

```markdown
我先识别到这些产品特征：
- 产品类型：
- 颜色/材质：
- 版型/结构：
- 细节特征：
- 可提炼卖点：
```

如果用户没有产品图但要求做一整套素材，先让用户补充产品图或基础信息，不要凭空编造产品细节。

### 第 2 步：拆解参考图 / 竞品图（可选）

只有用户提供参考图 / 竞品图 / 历史生成图时，才启动本步。拆解维度：

1. 风格（白底 / 场景 / 海报 / 信息图 / 编辑感）
2. 构图（居中 / 左右分栏 / 上文下图 / 长图分屏 / 拼贴）
3. 功能（点击 / 解释 / 证明材质 / 解决尺码 / 展示 SKU / 活动氛围）
4. 文案（主标题气质、卖点短句、信息密度）
5. 色彩（背景色 / 商品色 / 辅助色 / 字体色）
6. 连贯性（同一套图是否沿用背景 / 主色 / 字体 / 卡片 / 道具）
7. 可复用元素（光影、道具、标签、模特姿势）
8. 禁止复用元素（竞品品牌、原商品、原价格、原活动、原二维码）

输出格式（参考图拆解简报）见 `references/platforms/_sop-brief-template.md`。

### 第 3 步：确认素材类型

用户没说要做哪些图时，先列选项：

```markdown
你这次要做哪一组素材？可以直接选，也可以自己说数量：
1. 主图 1 张
2. 主图 1 张 + 副图 4-6 张
3. 详情页 6-8 段
4. SKU 图：每个颜色白底图 + 模特上身图
5. 活动海报 / 促销海报 1-4 张
6. 完整素材链路：主图/副图 + 详情页 + SKU + 活动海报
```

### 第 4 步：确认视觉风格

询问或确认风格时不要只问抽象风格词，给可执行的套图风格摘要：

```markdown
我建议这套图先按这个方向走：
- 套图风格：
- 背景/场景：
- 主色/字体：
- 光影质感：
- 版式组件：
- 人物/道具策略：
- 信息密度：

如果你认可，我就按这个方向继续出主图/副图/详情页提示词。
```

如果用户已经给出明确风格或参考图风格已经反推出来，就直接确认而不是重新问。

### 第 5 步：按模块逐步实现

通用推荐顺序：

1. 主图/副图（先做商品相册基础）
2. 详情页（建立购买理由）
3. SKU 图（颜色/规格）
4. 活动海报（节日/促销/上新）
5. 平台定制模块（A+、Rich Content、Pinterest Pin 等）

用户中途说"继续 / 其他几个呢 / 详情页呢 / 主图也生成一下"，沿用已经确认的产品信息、风格和数量继续，不要重新询问。

## 通用输出格式

```markdown
## {ID}. {图片类型} - {用途}
图片描述：{画面内容}
产品：{产品名 + 展示方式}
核心信息/卖点：{本图只表达一个核心信息点}
场景：{该平台类目适配场景}
图片文案：{无文字 / 直接生成中文文案：xxx / 直接生成英文 / 俄文 / 韩文...}
风格：{该平台电商审美 + 用户指定/参考反推风格}
光影：{真实、清晰、有质感}
构图：{主体占比、视角、信息层级}
比例：{1:1 / 3:4 / 9:16 / 16:9 / 970x600 / 750px 宽长图}
字体：{标题-.../ 正文-.../ 数字-...}
提示词：
```text
{可直接复制给 AI 生图工具的完整提示词}
```
合规检查：{该图风险点}
```

## 通用合规清单

输出前过一遍：

- [ ] 主图是否白底（Amazon、TikTok、Shopify main 等）。
- [ ] 主图是否无字、无 logo、无水印。
- [ ] 服装套图是否保持同一模特（脸、发型、身材一致）。
- [ ] 详情页是否共用同一套视觉系统（背景/主色/字体/卡片）。
- [ ] 是否编造了价格、优惠、起订量、库存、认证、销量。
- [ ] 是否出现未授权品牌 logo、二维码、联系方式、平台 UI。
- [ ] 是否使用了绝对化表达（best / #1 / 100% / guaranteed）。
- [ ] 图片内文字是否使用目标市场语言 + 正确字体支持。
- [ ] 单位制是否匹配目标市场（美 inch / 欧 cm / 东南亚按本地）。
- [ ] 多张图是否角度不同，不重复。
