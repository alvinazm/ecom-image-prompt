# 服装 / 鞋 / 帽 A+ 6 模块结构（基本骨架）

本文件定义 Amazon 服装、鞋子、帽子类 A+ Content / 详情页长图的标准 6 模块结构。结构源自 Totatwit 女装 T 恤 A+ 详情页（标杆参考），稳定可复用于任意服装 / 鞋 / 帽 SKU。

用户说“做 A+”“做详情页长图”“做服装套图”“做鞋/帽搭配图”时，默认用本结构起步，除非用户提供客户模板（template.md 等优先级更高）。

## M1 · Hero / 主 KV

**版式（970 宽三段式）**
- 左（约 20% 宽）：白色块，放品牌手写体 + 产品英文大标题 + 副标 + 标签胶囊
- 中（约 55% 宽）：真人主图，户外 / 绿植 / 自然光背景，配饰（墨镜、项链、包）点睛
- 右（约 25% 宽）：真人全身图 + 5 星好评排（米金色）

**关键元素**
- 品牌手写体 logo（米金色 #C9A876）
- 一句话定位标签：“2025 NEW ARRIVAL” / “SOLID BASIC TEE” 等
- 5 星好评（信任锚点，必须有真实评论支撑，不得伪造）

**文字策略**：左块大字 + 标签胶囊；字体方向 `soft elegant serif for logo + clean bold sans-serif for title`

**适配**
- 鞋：左块写鞋款名，中块单只鞋特写 + 上脚图，右块上脚全身 + 5 星
- 帽：左块写帽款名，中块戴帽特写，右块戴帽全身 + 5 星

## M2 · Lifestyle 拼贴

**版式**
- 3-4 张多角度真人图（正面 / 侧面 / 背面 / 半身 / 全身）
- 中央或一角放大字标题（如 “SPRING SUMMER FASHION”）
- 倾斜白框 + 阴影 = 杂志拼贴感
- 底部角落放品牌手写体

**关键元素**
- 多角度展示（证明版型 / 廓形）
- 季节 / 风格大标题（全大写）
- 品牌手写体落款

**适配**
- 鞋：多场景上脚拼贴（通勤 / 运动 / 约会）
- 帽：多戴法拼贴（正戴 / 反戴 / 斜戴 / 搭配不同发型）

---

## M3 · Details Show 详情

**版式（左中右三段）**
- 左：真人 + 黑白大标题 “DETAILS SHOW” + 一句面料描述
- 中：面料成分大字 + 3 个细节特写（领 / 袖 / 摆，编号 01 / 02 / 03）
- 右：真人半身

**关键元素**
- 面料成分（如 50% RAYON 45% POLYESTER 5% SPANDEX）
- 3 个工艺细节特写 + 数字编号 + 灰色小标题
- 一句话体感描述（ultra-soft / breathable / stretchy）

**适配**
- 鞋：3 特写 = 鞋面 / 鞋底 / 鞋带（或鞋头 / 后跟 / 内里）
- 帽：3 特写 = 帽檐 / 调节扣 / 刺绣标（或面料 / 内衬 / 通风孔）

**文字策略**：中块成分大字 `clean bold sans-serif`；编号 01/02/03 `modern condensed sans-serif`；米金色 #C9A876

## M4 · Versatile Collocation 搭配

**版式**
- 左：2 个真人造型（不同色产品 + 不同下装 / 搭配）
- 中：黑底白字大标题 “VERSATILE COLLOCATION”
- 右：白底 + “SUMMER TRENDY” + 4-5 个单品平铺图（配饰 / 包 / 鞋）

**关键元素**
- 百搭证明（至少 2 套搭配）
- 单品曝光（配饰平铺，增加交叉销售）

**适配**
- 鞋：左 2 套上脚造型，右平铺鞋 + 袜子 + 包
- 帽：左 2 套戴帽造型，右平铺帽 + 墨镜 + 围巾

## M5 · Scene 街拍拼贴

**版式**
- 左侧竖排大标题（如 “CUTE STRIPED TOPS”）
- 3-4 张不同场景真人（咖啡店 / 街角 / 室内 / 旅行）
- 底部：英文主标 + 中文副标 + 手写体 “Fashion”

**关键元素**
- 多场景 = 适配性强
- 中文副标（本地化，仅限非搜索流量位）
- 手写体落款

**适配**
- 鞋：通勤 / 咖啡店 / 公园多场景上脚
- 帽：街拍 / 海边 / 城市多场景戴法

## M6 · Size Chart 尺码表

**版式（左中右三段）**
- 左：模特头像 + 模特数据（身高 / 胸 / 腰 / 臀 或 鞋码 / 头围）
- 中：完整尺码表（S/M/L/XL/XXL × 关键维度）
- 右：真人坐姿 + 植物 / 原木背景

**关键元素**
- 模特数据（真实测量，标注 inch 误差允许值）
- 完整尺码表（确定性排版，AI 不直接画字）
- 减少退货的核心模块

**适配**
- 鞋：尺码表用 US / EU / UK + 脚长 cm
- 帽：尺码表用头围 cm（可调节款标 “One Size / 可调”）

**尺码表确定性排版**：用代码 / 设计工具后期叠表，不要依赖 AI 直接画字。表格列：SIZE / 关键维度1 / 关键维度2。

## 风险检查（通用）

- **生图模型内容审核**：主流生图模型对 “magic” / “instant” / “miracle” / “tummy control 单独强调” / “X Y Possibilities” 类宣传语敏感，会触发拒图。用产品特征描述替换（flutter ruffle sleeves / built-in shorts / crew neck / cap sleeve）。
- **夸大 claim**：不做无法证明的身材效果、医疗化、竞品对比、促销式 claim。
- **未包含物**：图里只出现买家实际会收到的内容；鞋子在服装图里仅为搭配，不纳入产品组成。
- **品牌 / logo**：不复制参考图上的第三方品牌、吊牌、logo，除非用户明确拥有该品牌。用用户品牌名或占位。
- **尺码 / 成分**：成分表、尺码表、护理图标用后期确定性排版，AI 直接画字易错。

## 后处理（Pillow 标准化）

生图模型常返回非精确像素。交付前用 Pillow 把每张 1792×1024 裁切 / resize 到目标模块尺寸：

- A+ 模块常用：970×500 / 970×600 / 970×420 / 970×360 / 970×300
- 长图：970 宽，分段生成后竖向拼接
- 主图：2000×2000；穿戴类副图：3:4 如 1500×2000

```python
from PIL import Image
im = Image.open("gen.png").resize((970, 500), Image.LANCZOS)
im.save("M3_details_970x500.png")
```

## 主副图结构（Main + Secondary，6 张）

服装 / 鞋 / 帽类 Listing 上半部分的"主图 + 副图"标准结构（区别于下方 A+ / 详情页长图）。

### 模块总览

| # | 模块名 | 页面位置 | 画布 | 模块目标 |
| --- | --- | --- | --- | --- |
| M0 | Main Image 主图 | `main-image` | 2000×2000（方形） | 搜索结果第一眼识别 + 白底真模 |
| S1 | 整体通勤场景 | `gallery-secondary`（2nd） | 1500×2000（3:4 竖版）| 完整呈现上身 + 场景锚点 |
| S2 | 背面 / 3/4 转身 | `gallery-secondary`（3rd） | 1500×2000（3:4）| 后背版型 + 臀腰线条 |
| S3 | 细节特写 4 宫格 | `gallery-secondary`（4th） | 2000×2000（1:1）| 面料 / 工艺 / 转化率 |
| S4 | 单穿西装外套场景 | `gallery-secondary`（5th） | 1500×2000（3:4）| 证明可独立穿搭 + 单品曝光 |
| S5 | 通勤生活方式 4 宫格 | `gallery-secondary`（6th） | 2000×2000（1:1）| 4 大场景 = 全天适配 |

### 通用规则

- **主图硬要求**：纯白背景 #FFFFFF + 真人模特穿着 + 无文字 / 无 logo / 无配饰 / 无边框 / 无促销角标
- **副图规则**：可加场景、可加细节标号、可以有少量文字（建议 1 个标题 + 3 个以内短标签）
- **模特一致性**：同一人物贯穿所有 6 张（短须或干净剃须，体型一致）
- **服装比例**：主图全身露出头到脚踝；副图 3:4 竖版裁头顶到鞋
- **细节图必须真实**：4 宫格里每个特写（面料 / 领子 / 口袋 / 纽扣）都必须是产品实际有的

### 子品类适配

| 子品类 | 主图调整 | 副图调整 |
| --- | --- | --- |
| 男士西装套装 | 3 件套全穿，真模站姿 | S3 细节换成西服面料 / 双排扣 / 腰头 / 袖扣 |
| 女装连衣裙 | 单件真模站姿或坐姿 | S3 换成领口 / 腰线 / 裙摆 / 拉链 |
| 童装 | 平铺或真人小孩（注意儿童模特合规） | S3 换成面料 / 纽扣 / 标签 / 走线 |
| 鞋子 | 单只鞋 3/4 角度，白底 | S3 换成鞋面 / 鞋底 / 鞋带 / 后跟 |
| 帽子 | 单顶帽 3/4 角度，白底 | S3 换成帽檐 / 帽顶 / 内衬 / 调节带 |

### 风险检查（主副图特化）

- T 恤 / 内搭印花：参考图常含第三方 IP（剧名 / 品牌 logo），必须改成纯色无字无 logo
- 配饰（鞋 / 表 / 包 / 香水）：**主图绝对不出现**，副图只在搭配场景出现 1-2 次
- 主图背景：必须是纯白 #FFFFFF，不能有阴影、渐变、地板线
- 模特年龄：服装类常见 25-35 岁，童装必须用童模，宠物服饰用人或宠物
- "world's first" / "best ever" / "luxury" 等夸大词在主图字面 claim 上禁用
