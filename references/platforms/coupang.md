# Coupang 套图子模块

> 本平台规则**全部内联于本文件**（无子目录），本文件即唯一事实源。这是本 skill **新增**的平台模块（补齐原套图 skill 缺失的 Coupang 入口）。

## 核心定位

Coupang 是韩国最大电商平台，**Rocket 配送** 是其核心差异化（"로켓배송 / 火箭配送 / 次日达"）。Coupang 用户对**韩文大字、火箭标识、品牌信任、参数感**敏感。视觉风格类似"韩版货架海报"：大字韩文、白色或浅色背景、品牌感强。

> ⚠️ **Coupang logo / Rocket 标识**：Coupang logo 和 "로켓배송 / Rocket" 商标不能由 AI 生图伪造。仅可使用通用描述（如"次日达""로켓배송"），不要画具体品牌 logo。如要使用 Rocket 标识作为合规卖点，需用户提供授权素材。

## 主图硬规则

- **比例**：默认 `1:1`（商品卡）。
- **背景**：白底优先（main image），但允许带浅色背景和大字韩文标题。
- **文字**：必须有韩文大号短标题（区别于 Amazon）；主标题占画面 30%-50%。
- **模特**：韩系审美，本地化模特气质（亚洲面孔、干净妆容）。
- **价格/活动元素**：可有"할인 / Discount"、"무료배송 / Free Shipping"、"로켓배송 / Rocket 配送"等通用运营元素，但需用户给具体数字。
- **平台 UI 元素**：禁止 Coupang logo、Rocket 商标具体 logo、收藏爱心、平台标识等。

## 主图 vs 副图 vs 详情页 区别

| 类型 | 业务位置 | 默认数量 | 推荐比例 | 核心任务 |
|---|---|---|---|---|
| 主图 | 搜索结果 / 推荐流 | 1 | 1:1 | 抢点击 + 强韩文化 |
| 副图 | 商品相册第 2-N 张 | 4-6 | 1:1 / 3:4 | 功能 / 细节 / 场景 / 规格 |
| 详情页 | 商品详情长图 | 6-8 段 | 3:4 / 9:16 | 转化 + 信任 |

| 活动海报 | Rocket 大促 / 节日 | 1-4 | 1:1 / 3:4 / 9:16 | 主题 + 韩文大字 |

## 工作流

1. **识别品类**：服装 / 3C / 家居 / 美妆 / 食品 / 母婴 等。
2. **本地化**：韩系模特、亚洲场景、韩文文案、Hangul 字体支持。
3. **风格确认**：未给时给 4-6 个可选风格方向。
4. **输出确认稿**：每张图按 Coupang 规则出确认稿。
5. **交付提示词 + 文案**：本 skill 只出可复制提示词，不执行生图；用户确认后交付，由用户自行粘贴到生图工具生成。

## 主图 SOP

主图必须做到两件事：
1. 一眼看懂商品是什么。
2. 一眼看懂它的主要优势 + 韩文大字标题。

主图提示词要包含：
- 产品完整描述（品类、颜色、材质、结构、细节）
- 卖点：1-2 个最核心的
- 场景：韩系日常（居家/通勤/咖啡店/地铁）
- 构图：1:1，主体占画面 60%-75%
- 文案：必须有韩文大号短标题（如 `로켓배송 가능`、`무료배송`、`신제품 출시`）— 但具体价格必须用户给
- 模特：韩系审美，本地化模特气质

## 副图 SOP

每张只讲一个信息点：
1. 角度变化（侧面/背面/3/4）
2. 细节特写（面料/材质/接口）
3. 功能演示
4. 场景图（韩系日常）
5. 规格/参数图
6. SKU 多色图

## 详情页 SOP

按购买决策顺序：
1. 首屏利益点（韩文大字）
2. 痛点场景
3. 功能说明
4. 材质/参数
5. 工艺/规格
6. 场景收尾
7. 信任收尾（品牌 / 售后）

详情页必须先定义"连续详情页视觉系统"，再逐张输出。

## 文案与字体

| Korean | Noto Sans KR / NanumSquare / Apple SD Gothic Neo / Pretendard |

- 标题字重：Bold / Heavy（900）
- 正文：Regular / Medium（400-500）
- 数字：DIN / Pretendard Variable

## 韩文标题常用写法

- 利益点：`무료배송`（包邮）/ `할인 중`（折扣中）/ `신제품 출시`（新品上市）
- 信任：`로켓배송 가능`（支持 Rocket 配送）/ `정품 보장`（正品保证）/ `7일 교환`（7天可换）
- 限时：`오늘만`（仅今日）/ `한정 수량`（限量）
- 数字：`최대 50% 할인`（最高 5 折）/ `1+1`（买一送一）
- 节日：`설날 선물`（春节礼物）/ `추석 선물`（中秋礼物）/ `화이트데이`（白色情人节）

## 活动海报 SOP

Coupang 大促节点：
- 로켓배송 Rocket Day（每月一次）
- 黑色星期五 Black Friday
- 双 11 / 双 12（11.11 / 12.12）
- 설날 / 추석 / 크리스마스

启动时询问：活动主题 / 输出数量和比例 / 是否复刻参考图风格。

规则：
- 必须有活动主题、产品焦点
- 价格、优惠、券、赠品必须来自用户；未提供时不要编造
- 可以直接生成韩文活动标题和短利益点
- 避免绝对化用语

## 合规底线

- 主图：白底或浅色背景，无价格欺骗，无夸大宣传。
- 副图 / 详情页：可有场景和文字，但不能做虚假、无法证明、医疗化、竞品对比、促销式 claim。
- 不编造价格、起订量、库存、认证、销量。
- 不生成 Coupang logo、Rocket 商标具体 logo、店铺名、收藏爱心、平台 UI。
- 韩国合规：药品 / 化妆品 / 食品宣称严格，夸大或医疗化表述会被下架。
- 不使用未授权品牌 logo、二维码、联系方式。
