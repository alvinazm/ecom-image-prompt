# 1688 套图子模块

> 本文是 1688 入口索引：只含平台定位、平台硬规则和路由。各图类型的完整规则以 `1688/` 子目录为**唯一事实源**，做具体图类型时必读对应子文件。

## 平台定位

1688 的图是采购判断图，不是品牌种草图：要让买家快速看懂"卖什么、规格是什么、优势是什么、能不能拿货"。

## 平台硬规则

1. **信息清晰优先于美感**。
2. **规格、材质、型号、尺寸、颜色必须前置**。
3. **信任优先于情绪**：工厂/仓库/质检/发货/定制能力要可视化。
4. **主图一眼识别商品**，白底图必须规范。
5. **不要做成过度 DTC 品牌海报**，避免淘宝/Shopify 式情绪化叙事。
6. **不编造价格、起订量、库存、认证、产能、发货时效**。
7. 所有提示词必须可直接复制给 AI 生图工具使用。

## 默认素材链路（用户未指定时）

主图/白底图 → 详情卖点图 → 规格参数图 → 工艺细节图 → 场景应用图 → 对比图 → 实力图/定制图/包装发货图 → 活动图。

## 默认风格分支

1. **白底规范型** — 标准商品图、SKU 图、上架基础图。
2. **工厂实力型** — 源头店、工厂店、批发商、定制商家。
3. **批发卖点型** — 爆款、订货页、批量采购页。
4. **参数说明型** — 工具、电子配件、家居百货、工业品。
5. **场景应用型** — 家居、服装、日用、包材、礼品。
6. **活动促销型** — 上新、清仓、大促、订货会。

## 类目默认策略（简版）

| 类目 | 主图重点 | 详情图重点 |
|---|---|---|
| 服装 / 纺织 | 版型、材质、颜色、穿着效果 | 面料、尺码、版型、搭配、适用季节 |

| 包装 / 礼品 / 节庆 | 成套感、规格、材质和送礼属性 | 尺寸、工艺、内衬、定制能力 |

## 与其他平台的边界

- 不把 Shopify 式高级品牌叙事直接搬到 1688。
- 1688 优先供货、批发、规格、工厂、信任。
