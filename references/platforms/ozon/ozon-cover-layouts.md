# Ozon 封面图版式规则

只要生成 Ozon 封面图、主图、搜索卡图、商品卡首图，就使用本文件。Ozon 封面常见做法不是简单白底产品图，而是信息密度较高的电商海报卡片。

## 封面总原则

- 默认比例 `3:4`。
- 俄文大标题必须醒目，通常是画面最大文字。
- 大标题必须明确写成“超大标题”，占画面宽度 `35%-55%` 或高度 `12%-22%`，移动端商品卡也能读清。
- 标题只用 1-2 行，每行 1-3 个俄文词，避免为了塞信息把字变小。
- 产品必须是主视觉，清楚、完整、可识别。
- 可使用顶部用途条、参数圆章、卖点信息卡、底部图标栏、局部放大圈。
- 所有文字必须直接写进生图提示词，让模型原生生成在图片里。
- 尺码、容量、数量、材质、品牌、包装件数只能来自用户提供或图片明确可见信息。
- 缺少事实时，用安全泛化文案，例如产品类型、用途、使用场景、尺码检查提醒，不编造参数。
- 不要价格、折扣、评分星星、评论数、收藏爱心、Ozon 标识、二维码、联系方式、平台 UI。
- 不要把用户截图里的蓝色折扣条、商品价格、划线价、爱心按钮、平台卡片边框写进生成图；这些属于平台页面 UI，不属于产品封面本体。

## 常用封面结构

### 类型 A：大标题产品中心封面

适合书包、鞋、箱包、收纳、电器、小家电、家居用品、日用品。

构图：
- 顶部放一条短用途胶囊，例如 `для учёбы, путешествий и города`。
- 中上部放超大俄文标题，通常 1-2 行。
- 产品居中或居中偏下，占画面主体。
- 左侧或右侧放参数圆章，例如容量、尺寸、数量；只有用户提供真实数据时才写数字。
- 底部放 3-5 个图标卖点栏，每个图标配 1 条短俄文。
- 背景白色、浅灰、浅蓝、浅米色，整体干净明亮。

适合俄文：
- `ВМЕСТИТЕЛЬНЫЙ РЮКЗАК`
- `ДЛЯ УЧЁБЫ И ГОРОДА`
- `много карманов`
- `отделение для ноутбука`
- `водоотталкивающий материал`
- `дышащие лямки`
- `идеален для путешествий`

如果没有容量、电脑尺寸、防水事实，不要写 `30 л`、`до 15,6"`、`водоотталкивающий материал`。

### 类型 B：多件装货架封面

适合袜子、连裤袜、内衣、毛巾、香薰、礼盒、收纳套装、多件装消耗品。

构图：
- 大标题在顶部或左上，产品类型必须一眼可见。
- 产品成组堆叠、排列或盒装展示，占画面 45%-65%。
- 如果用户提供数量、尺码、容量、香型数量，可以用大数字圆章或横条突出。
- 可放 3-5 个小图标卖点，例如舒适、轻盈、弹性、适合日常、适合礼物。
- 背景按品类选择浅色、深色高级感、家居场景或棚拍场景。

适合俄文：
- `МУЖСКИЕ НОСКИ`
- `КОРОТКИЕ НОСКИ`
- `ПРЕМИУМ КОЛЛЕКЦИЯ`
- `НАБОР`
- `мягкая резинка`
- `на каждый день`
- `подарочный набор`

数量、尺码、棉含量、香型数量只在用户明确提供时使用。

### 类型 C：模特商品卡封面

适合女装、男装、鞋、配饰、穿搭类商品。

构图：
- 模特穿着产品，模特与产品是主视觉。
- 大标题放左侧、左上或顶部，模特放右侧或居中偏右。
- 可加 2-4 个短信息块，说明版型、用途、季节、套装组成。
- 可加局部放大圈展示面料、领口、袖口、纹理、鞋底等细节。
- 服装类套图必须沿用同一个模特。
- 大标题要比所有信息块明显大很多，不能缩成普通标签。

适合俄文：
- `ПЛАТЬЕ`
- `КОСТЮМ`
- `КРУЖЕВНОЙ КОМПЛЕКТ`
- `женское`
- `на каждый день`
- `для вечера`
- `свободная посадка`

### 类型 D：卖点信息海报封面

适合需要强解释的产品，也适合详情页第一屏或副图首屏。

构图：
- 右侧或下方放产品使用场景大图。
- 左侧放大标题和副标题。
- 中部放 3-4 个信息卡，每个卡片包含小图标、短标题、1 句短说明。
- 可加一个局部放大圈，用箭头指向产品细节。
- 底部可放 3 个横向卖点图标。
- 信息量可以高，但文字必须大、短、可读。
- 如果是细节/局部类副图，不要套完整模特封面；改用产品局部大图 + 超大标题 + 少量功能卡 + 圆形放大镜。

适合俄文：
- `МЯГКАЯ РЕЗИНКА БЕЗ ДАВЛЕНИЯ`
- `КОМФОРТ В ТЕЧЕНИЕ ВСЕГО ДНЯ`
- `не пережимает`
- `не сползает`
- `комфорт весь день`
- `подходит для длительной носки`

信息卡只能写真实或安全泛化卖点，不要写医疗功效、绝对承诺、假认证。

### 类型 E：高级礼盒/暗色封面

适合香水、香薰、礼盒、饰品、节日礼品。

构图：
- 深色或高级材质背景，产品盒装居中。
- 大标题可以使用金色、白色、黑金风格，但要保持清晰。
- 顶部或中部放产品集合名称，下面放 3-5 个小卖点图标。
- 底部可展示不同款式、香型或颜色；只有用户提供真实信息时才写名称和数量。
- 不要生成假品牌、假奖章、假认证。

适合俄文：
- `ПРЕМИУМ КОЛЛЕКЦИЯ`
- `подарочный набор`
- `для дома и офиса`
- `стильный подарок`

## 选择规则

- 书包、箱包、工具、日用品：优先类型 A。
- 袜子、内衣、多件装、礼盒：优先类型 B。
- 女装、男装、鞋、配饰：优先类型 C。
- 需要解释功能和舒适度的副图首屏：优先类型 D。
- 香薰、礼品、饰品、节日套装：优先类型 E。
- 如果用户提供竞品截图，先判断截图属于哪种结构，再迁移布局，不照抄品牌、价格、折扣、平台 UI。

## 提示词写法

封面提示词必须写清：

- 这是 Ozon 封面图 / 主图 / 搜索卡首图。
- 比例 `3:4`。
- 使用哪种封面类型。
- 产品在画面中的位置和大小。
- 标题、信息卡、圆章、底部图标栏里的俄文原文。
- 俄文主标题超大，是画面最大文字，移动端商品卡也能读清。
- 文字直接生成在图片里，不后期添加。
- 不要价格、折扣、评分、爱心、Ozon 标识、二维码、联系方式、平台 UI。

示例句式：

```text
给这个{name}生成一张 Ozon 商品卡封面图，比例3:4，使用大标题产品中心封面，顶部用途条写“...”，中上方超大标题写“...”，产品居中占主体，左侧参数圆章写“...”，底部 4 个图标卖点写“...”，所有俄文文字直接生成在图片里，清晰可读，不要价格、折扣、评分、爱心、Ozon 标识和二维码。
```
