# Ozon 全品类图片版式规范

所有 Ozon 品类都先应用本规范，再叠加品类细分规范。Ozon 封面图通常是“大字货架海报图”，不是无文字极简商品图。

## 全局默认

- 所有图片都要符合 Ozon 电商审美，适配 Ozon 平台。
- 封面图 / 主图默认比例：`3:4`。
- 详情页模块图默认比例：`3:4`。
- 详情页长图：`750px` 宽，高度不限，纵向拼接。
- 按用户要求生成指定数量；图片上限 15 张；默认最优 6-10 张。
- 默认结构：主图 1 张，卖点图 2-5 张，细节图 1-2 张，场景图 1-2 张，尺寸图 1 张，信息图 1-2 张。
- 所有图片必须采用不同拍摄视角、摆放方式或构图方式，避免同角度、同位置重复展示。
- 用户要求中文提示词时，输出中文短句；图片里给买家看的文字仍然必须是俄文。

## 字号与文字层级硬规则

Ozon 图片不是小字说明页。默认要让移动端商品卡也能看清主信息。

- 所有封面、卖点图、细节图、信息图只要带标题，俄文标题必须写成“超大标题”。
- 超大标题必须占画面宽度的 `35%-55%`，或占画面高度的 `12%-22%`，不能只是小标签。
- 标题优先使用 1-2 行，每行 1-3 个俄文词，宁可短也不要小。
- 副标题比主标题小，但仍要明显可读，不能变成密集说明文字。
- 信息卡文字只放 1 个短标题或 1 句短说明；不要密集小字、长段落。
- 生成提示词时必须明确写：“俄文主标题要非常大，是画面最大文字，移动端商品卡也能读清”。
- 细节图和详情模块同样可以有大标题；不要只在封面要求大字。

## 封面图规则

Ozon 全部品类封面默认需要大标题。

封面图要求：

- 比例 `3:4`。
- 标题要大，俄文标题是最大文字，必须是超大标题。
- 产品正面居中，或使用强主体构图。
- 背景以浅色、白底、干净棚拍为主；也可按品类做海报场景。
- 画面要有足够大的俄文信息，方便在商品卡片里快速看懂。
- 不做无字封面，除非用户明确要求“不要字 / 干净图”。

适合出现在封面的文字类型：

- 产品类型：`ПЛАТЬЕ`、`РУБАШКА`、`НОСКИ`、`КРЕМ`、`СТЕЛЬКИ`、`ОТПАРИВАТЕЛЬ`。
- 核心参数：容量、功率、尺码范围、数量、SPF、材质、档位数量。
- 主卖点：舒适、防护、快速、支撑、易用。
- 所有数字和事实必须来自用户提供或产品图可见信息。

不要生成平台 UI：

- 不要价格。
- 不要折扣。
- 不要评论数。
- 不要评分星星。
- 不要收藏爱心。
- 不要 Ozon 标识。
- 不要“本周折扣”。
- 不要“来源”标签。
- 不要支付或后付费标签。
- 不要二维码。
- 不要联系方式。

## 图片类型

### 主图

核心句式：

```text
给这个{name}生成一张，符合Ozon电商审美，适配Ozon平台的电商主图，比例3:4，标题要大，正面居中摆放，浅色白底背景。
```

需要补充：

- 直接写明要渲染的俄文大标题。
- 写明 2-4 个俄文规格或卖点短句。
- 写明产品角度和摆放方式。
- 写明不要平台 UI、价格、折扣、二维码、联系方式。

### 卖点图

核心句式：

```text
给这个{name}生成一张，符合Ozon电商审美，适配Ozon平台的电商卖点图，比例3:4，使用斜侧、俯视、侧方或半场景角度，结合{maidian}对应单个卖点。
```

规则：

- 一张图只讲一个卖点。
- 默认渲染一个清晰俄文超大标题或卖点短句。
- 可以展示产品近景、功能状态、简单对比，但必须基于事实。
- 当用户参考图是信息量较高的 Ozon 副图时，卖点图可以升级为“卖点信息海报”：大标题 + 副标题 + 3-4 个信息卡 + 小图标 + 局部放大圈 + 底部卖点条。
- 卖点信息海报仍然围绕一个核心卖点展开，信息卡是对这个卖点的拆解，不要把无关卖点塞满整张图。
- 文字要比普通详情图更大，适合商品卡或移动端快速扫读。

### 细节图

核心句式：

```text
给这个{name}生成一张，符合Ozon电商审美，适配Ozon平台的电商细节图，比例3:4，近景特写角度，展示产品局部细节。
```

规则：

- 展示纹理、材质、接口、缝线、纽扣、包装、开合结构、刷头、瓶口、表面质感等。
- 默认加一个俄文超大标题或大号细节标签。
- 对服饰、鞋包、家居纺织等材质类商品，细节图优先做“产品局部大图 + 超大标题 + 2 个功能卡 + 圆形放大镜”，不要默认做全身模特图。
- 不编造材质成分和技术参数。

### 场景图

核心句式：

```text
给这个{name}生成一张，符合Ozon电商审美，适配Ozon平台的电商场景图，比例3:4或16:9，生活化环境中自然摆放或使用角度。
```

规则：

- 展示真实使用环境。
- 默认加一个俄文场景或用途短句。
- 产品必须是视觉重点。

### 尺寸图

核心句式：

```text
给这个{name}生成一张，符合Ozon电商审美，适配Ozon平台的电商尺寸图，比例3:4，结合{extra}尺寸数据，使用俄罗斯常规尺码表达，仅展示尺寸信息。
```

规则：

- 只使用用户提供的尺寸、尺码、模特参数、包装数量。
- 不编造尺寸。
- 没有尺寸数据时，改成尺码检查提醒，不做假数据。

### 信息图

核心句式：

```text
给这个{name}生成一张，符合Ozon电商审美，适配Ozon平台的电商信息图，比例3:4或1:1，结合{extra}非尺寸类额外信息，不包含任何尺码内容。
```

规则：

- 使用 2-4 个模块。
- 解释卖点、用途、包装内容、护理方式、兼容性、已知规格。
- 信息图不混入尺寸表，除非它本身就是尺寸图。
- 信息图可以采用 Ozon 常见的左文右图或上文下图结构：一侧放产品/使用场景，一侧放 3-4 个信息卡，底部放 3 个图标卖点。
- 可使用圆形局部放大框和箭头指向真实细节，但不要遮挡产品主体。
- 信息卡标题用 2-5 个俄文词，说明用 1 个短句；不要长段落和密集小字。

### 详情页长图

核心句式：

```text
给这个{name}生成一张，符合Ozon电商审美，适配Ozon平台的详情页长图，750px宽度纵向拼接，模块顺序为卖点、细节、场景、尺寸、信息。
```

规则：

- 纵向拼接。
- 每个模块都有清楚标题。
- 买家可见文字保持简短俄文。

## 输出格式偏好

用户要提示词列表时，默认短句罗列：

- 不写长解释。
- 不加多余备注，除非缺少关键事实。
- 不加装饰符号。
- 可以编号。
- 每条提示词都能直接复制去生图。

## 合规检查

- 封面为 `3:4`，默认有大俄文标题。
- 详情模块为 `3:4`，除非用户另有要求。
- 详情长图按 `750px` 宽。
- 图片角度和构图不重复。
- 图片内买家文案为俄文，并直接渲染进图。
- 不编造事实，不做假品牌、假认证、平台 UI、价格、折扣。
