# Hillsusu 办公椅 (Hillsusu-desk) Ozon 套图品类规范

Hillsusu 人体工学办公椅的 Ozon 套图视觉系统，基于 11 张 Hillsusu 品牌办公椅套图拆解沉淀。适用于 Hillsusu 全系办公椅产品，以及同类型"白色网面+铝合金五星脚+模块化多维调节"人体工学椅品牌的 Ozon 套图复刻。

## 品牌视觉系统

### 品牌色

| 角色 | 颜色 | 用途 |
|---|---|---|
| 主色·深蓝 | `#1a2c5b` 实色 / 深蓝→黑色渐变 | 主图背景、科技感装饰、参数块底色 |
| 副色·浅蓝 | `#6b8ed4` 实色 / 浅蓝渐变 | 副图大字、信息块、尺寸线、箭头 |
| 强调·紫色 | `#8a4ad9` 实色 | 品牌 Hillsusu logo 手写体（唯一紫色） |
| 中性·暖白 | `#f5f0eb` 浅暖色 | 办公空间墙面色，让椅子更突出 |
| 中性·米白 | `#e8e0d4` 暖白渐变 | 办公空间地板色 |
| 文字深 | `#1a2c5b` | 标题文字（与主色统一） |
| 文字浅 | `#888888` | 描述段落、辅助文字 |
| 白色 | `#ffffff` | 椅子主体色、字底色 |

### 字体

- **俄文大写无衬线**，加粗，主标题特大。
- 主标题：Hillsusu 全套图固定 1-2 行大写俄文，占画面宽度 50-65%。
- 副标题：俄文小字补充，与主标题颜色一致或浅蓝。
- 描述段：浅灰小字，3-5 行短文。
- **品牌 logo**：`Hillsusu` 用**紫色手写体**（与产品无关），仅在品牌介绍图（第 4 张）出现。
- 椅子上的 logo：椅背顶部小印 `Hillsusu` 字母（白色小字），可在产品特写图保留。

### Logo 策略

| 图型 | Logo 处理 |
|---|---|
| 主图 | 不放 Hillsusu 大 logo（避免抢戏），可在椅背顶部小印 |
| 品牌介绍图 | 必放 Hillsusu 紫色手写体 logo |
| 卖点/细节/尺寸/证书图 | 不放 Hillsusu 大 logo |

### 模特策略

- Hillsusu 主图和腰托图使用模特展示**真实使用场景**。
- 模特特征：**男性，25-35 岁，年轻商务风**，深色或棕色短发，干净利落。
- 主图（图 1）：坐姿，米色/白衬衫，深邃轻松感。
- 腰托图（图 3）：坐姿侧脸，戴眼镜，强调"办公久坐"场景。
- **同一品牌套图建议保持同一模特**（同一张脸、同一发型、同一身材比例）；如品牌方有两套模特资源可分开使用，但要明确用途。
- 其余 9 张图均无模特，聚焦椅子本体和参数。

### 背景策略

| 图型 | 背景 |
|---|---|
| 主图 | 深蓝科幻感背景 + 蓝色光带/光晕，营造科技高端感 |
| 信息图/特写图 | 浅色办公空间（白墙/暖白地板/绿植点缀/落地窗），真实感 |
| 尺寸图 | 白色背景（技术图纸感），少量蓝色尺寸线/箭头 |
| 证书图 | 浅色办公空间，证书框放在椅子前方 |

## 版式分类

### 类型 A：深色品牌主图（科技海报）

适用：主图、第一张封面。

**结构：**
- 深蓝黑渐变背景（约 `#1a2c5b` 到 `#0a1530`），带蓝色光带/光晕装饰（科幻感）。
- 中上偏左：超大俄文标题 `ЭРГОНОМИЧНОЕ КРЕСЛО`，白色加粗，1-2 行，占画面宽度 55-65%。
- **模特居中偏左**，坐姿，米色/白衬衫，看向远方，姿态放松。
- 椅子居中或中央偏下，45 度侧视角。
- **右侧 3 个深蓝色矩形参数块**（带圆角），白字大数字 + 浅蓝小字标签：
  - `МАКСИМАЛЬНАЯ НАГРУЗКА 180 КГ`
  - `НАКЛОН СПИНКИ 90°-135°`
  - `РОСТ ЧЕЛОВЕКА 160-195CM`
- 装饰：底部蓝色光带（横向线/弧线），营造科技感。
- 不放 Hillsusu 大 logo。

**俄文模板：**
- 主标题：`ЭРГОНОМИЧНОЕ КРЕСЛО` / `ОФИСНОЕ КРЕСЛО` / `КОМПЬЮТЕРНОЕ КРЕСЛО`
- 参数块：`МАКСИМАЛЬНАЯ НАГРУЗКА` / `НАКЛОН СПИНКИ` / `РОСТ ЧЕЛОВЕКА`

### 类型 B：浅色办公空间概览图（多块信息）

适用：副图首屏，"详细概览"类。

**结构：**
- 浅色办公空间背景（白墙+暖白地板+绿植）。
- 左侧 60-65%：**椅子正面大图**，白色网面+银白框架，居中偏左。
- 右侧 35-40%：**垂直排列 4-6 个浅蓝矩形信息块**，每块包含：
  - 1 张工具/功能特写小图
  - 1 行大写俄文主词
  - 1 行小字补充
- 信息块从上到下排列，块间留白。
- 顶部大标题：`ДЕТАЛЬНЫЙ ОБЗОР`，蓝色或紫色，1-2 行。
- 不放 Hillsusu 大 logo。

**俄文模板：**
- 顶部：`ДЕТАЛЬНЫЙ ОБЗОР` / `ОБЗОР ФУНКЦИЙ` / `ОСНОВНЫЕ ПРЕИМУЩЕСТВА`
- 信息块（5-6 个，按品牌功能改）：
  - `АДАПТИВНАЯ ПОЯСНИЧНАЯ ПОДДЕРЖКА`（自适应腰托）
  - `ОТКИНЬТЕСЬ НАЗАД НА 90°-135°`（后仰调节）
  - `УГОЛ НАКЛОНА 120°`（腰托角度）
  - `ВРАЩЕНИЕ 360°`（旋转）
  - `КАЧАЮЩИЙСЯ РЕГУЛЯТОР ДАВЛЕНИЯ`（气压调节）
  - `РАСТЯГИВАТЬ 41 СМ`（拉伸）

### 类型 C：模特 + 腰托功能特写

适用：副图，"核心功能"类（腰托、头枕、扶手等）。

**结构：**

- 副标题：`ЭТО БУДЕТ ВАШЕ ПОСЛЕДНЕЕ КРЕСЛО`，浅灰小字。

  - `Высота спинки 6 см`
  - `Регулируется в 3 положениях`

- 或：`КРЕСЛО С ПОЯСНИЧНОЙ ОПОРОЙ` / `АДАПТИВНАЯ ПОДДЕРЖКА ПОЯСНИЦЫ`
