# 小米数码 (xiaomi-3c) Ozon 套图品类规范

小米品牌/小米生态链 3C 及周边小件商品在 Ozon 上的主副图视觉系统。基于小米指甲刀套装的 9 张竞品图拆解沉淀，适用于小米生态链产品或同类型"白盒 + 不锈钢工具 + 收纳场景"小件 3C 周边。所有图片中**保留小米品牌 logo**（只要产品本身是小米或米家系），因为小米的品牌背书是转化核心。

## 品牌视觉系统

### 品牌色

| 角色 | 颜色 | 用途 |
|---|---|---|
| 主色·小米橙 | `#FF6700` 实色 / 橙→深橙红渐变 | 大标题渐变、品牌徽章、"5B1/数量"圆章 |
| 副色·警示红 | `#C8161D` 实色 | 红色信息块（卖点卡/参数块），与橙色形成对比 |
| 文字深灰 | `#333333` | 副标题、正文 |
| 文字中灰 | `#888888` | 描述段落、图标签名 |
| 主图背景 | `#1a1f2e` 深蓝黑 | 主图专用 |
| 副图背景 | `#ffffff` 白 / `#f5f5f5` 浅灰 | 副图、信息图主背景 |
| 细节图背景 | `#c8c8c8` 中灰 | 工具特写背景，让银色不锈钢反光更明显 |

### 字体

- **俄文大写无衬线**，加粗，主标题特大。
- 主图主标题：`НАБОР МАНИКЮРНЫЙ` —— 占画面宽度 50-60%，白色。
- 副图主标题：1-2 行大写俄文，**橙红渐变或深灰**。
- 描述段落：浅灰小字，3-4 行短文。
- 图标签名：浅灰，小号，仅在工具展示图使用。

### Logo 策略

- **带文字的图**（主图、卖点图、信息图）：右上角放 `MI xiaomi`（橙色方块+白字+黑字"xiaomi"）。
- **纯产品图**（白底产品俯视图）：不放 logo，让产品本身说话。
- Logo 固定位置右上角，不要散落或居中。

## 版式分类

### 类型 A：深色主图（品牌徽章 + 产品居中）

适用：主图、第一张封面。

**结构：**
- 深蓝黑背景（约 `#1a1f2e`），渐变到深紫蓝。
- 左上角：`MI xiaomi` 品牌 logo。
- 中上偏左：超大俄文主标题，**白色加粗**，1-2 行。
- 右上角：橙红渐变环形徽章，中心写卖点数字（如 `5B1`、`6 в 1`、`10 шт`）。
- 主体中央：产品实物（打开的收纳盒+工具全展开），**占据画面 50-60%**。
- 产品下方放短俄文白色胶囊标签（如 `НЕРЖАВЕЮЩАЯ СТАЛЬ`）。
- 底部：圆形认证徽章 + 短俄文（如 `ТОВАР СЕРТИФИЦИРОВАН`）。
- 装饰：底部黑色金属栅格/竖条纹理点缀。

**俄文模板：**
- `НАБОР МАНИКЮРНЫЙ`
- `НАБОР ИНСТРУМЕНТОВ`
- `МАССАЖЁР`
- `ТРИММЕР`
- 圆章数字：`5В1` / `6 В 1` / `10 ШТ`
- 白色胶囊：`НЕРЖАВЕЮЩАЯ СТАЛЬ` / `АККУМУЛЯТОР` / `ВЛАГОЗАЩИТА`
- 底部认证：`ТОВАР СЕРТИФИЦИРОВАН` / `ГАРАНТИЯ 1 ГОД`

### 类型 B：红色色块卖点信息卡（白底）

适用：副图首屏，介绍产品核心卖点。

**结构：**
- 白色背景，干净。
- 右上角：`MI xiaomi` logo。
- 左上：大标题（灰色或黑色）`ФУТЛЯР ДЛЯ ХРАНЕНИЯ`，副标题灰色小字 `с магнитной фиксацией`。
- **左侧：红色长方形信息块**（约占画面 1/3 宽，70% 高），块内白字列 3 个卖点：每个卖点 = 1 行大写主词 + 1-2 行小字解释。
- **右侧：产品大图**，俯视或 45 度角打开的收纳盒，工具清晰可见。
- 信息卡用 `[]` 角部弱化，无边框阴影，保持现代极简。

**俄文模板：**
- 大标题：`ФУТЛЯР ДЛЯ ХРАНЕНИЯ` / `КОМПАКТНЫЙ ДИЗАЙН` / `УДОБНО БРАТЬ С СОБОЙ`
- 副标题：`с магнитной фиксацией` / `для дома и поездок` / `для ежедневного ухода`
- 红色块内卖点（3 个）：
  - `ПРАКТИЧНЫЙ` + `кейс выполнен из ударопрочного ABC-пластика`
  - `КОМПАКТНЫЙ` + `удобно брать с собой`
  - `СТИЛЬНЫЙ` + `лаконичный белый футляр`
  - 或：`ПРОЧНЫЙ` / `ЛЕГКИЙ` / `БЕЗОПАСНЫЙ` / `УНИВЕРСАЛЬНЫЙ`

### 类型 C：尺寸/参数信息图（白底）

适用：副图，标注产品尺寸、重量、数量。

**结构：**
- 白色背景。
- 右上角：`MI xiaomi` logo。
- 左上：大标题 `РАЗМЕР`（灰色大字）。
- 标题下：红色圆角色块（约 200x60px），白字 `Вес: 100 г`。
- 中央：产品俯视展开图（收纳盒+工具全展示）。
- 产品周围：黑色细尺寸线 + 数字（`104 mm`、`65 mm`）。
- 简洁、参数感强。

**俄文模板：**
- 标题：`РАЗМЕР` / `ПАРАМЕТРЫ` / `ХАРАКТЕРИСТИКИ`
- 红色块：`Вес: 100 г` / `Длина: 12 см` / `Ёмкость: 500 мАч`
- 尺寸线（产品真实测量）：`104 mm` / `65 mm` / `12 см`
- 不要编造尺寸数字；只有用户提供的真实数据才放。

### 类型 D：工具图标阵列 + 场景图

适用：副图，展示多件套组成。

**结构：**
- **上半部分**：5 个圆形工具图标，3+2 布局（3 上 2 下）或 1 行 5 个。每个圆形 = 工具特写小图 + 下方 1-2 行俄文标签（橙色或灰色小字）。
- **下半部分**：灰色桌面/底色产品场景照——打开的收纳盒+5 件工具**散开摆放**（不规则排列），展示真实使用摆放感。
- 无大标题（已在前面封面/卖点图讲完），仅用图标+场景。

**俄文模板（工具标签，按真实品类改）：**
- 指甲刀套：`ПРЯМЫЕ КУСАЧКИ` / `КОСЫЕ КУСАЧКИ` / `НОЖНИЦЫ` / `ПИЛОЧКА ДЛЯ НОГТЕЙ` / `УШНАЯ ПАЛОЧКА`
- 螺丝刀套：`КРЕСТОВАЯ` / `ПЛОСКАЯ` / `ШЕСТИГРАННИК` / `ПИНЦЕТ` / `МАГНИТНЫЙ ДЕРЖАТЕЛЬ`
- 厨房工具：`НОЖ` / `ТОЧИЛКА` / `ОТКРЫВАЛКА` / `ШПАЖКА` / `ЛОПАТКА`

### 类型 E：橙红渐变大标题 + 灰色背景产品特写

适用：副图，单点卖点细节图（每张只讲 1 个功能点）。

**结构：**
- **顶部**：橙红渐变大标题（橙 `#FF6700` → 深橙红），**1 行大写俄文主词 + 1 行小字补充**，占画面顶部 25%。
- 主标题下：浅灰短描述段落（3-4 行），说明该功能点。
- 中央偏下：产品**单件特写**（如剪刀、挖耳勺、指甲钳）放在中灰背景上，**反光质感强**。
- 偶尔出现人手/手部局部（手持工具特写），增加使用感。
- 无 logo（聚焦功能）。

**俄文模板：**
- `ФУТЛЯР ДЛЯ ХРАНЕНИЯ` + `С МАГНИТНОЙ ФИКСАЦИЕЙ` + 描述"磁性收纳不掉"
- `ВСЕ ИНСТРУМЕНТЫ` + `ИЗ НЕРЖАВЕЮЩЕЙ СТАЛИ` + 描述"420/430 不锈钢"
- `МАНИКЮРНЫЕ НОЖНИЦЫ` + `ДЛЯ АККУРАТНОЙ РАБОТЫ` + 描述"双刃斜口"
- `УШНАЯ ПАЛОЧКА` + `ДЛЯ БЕРЕЖНОЙ ОЧИСТКИ` + 描述"圆滑单弯"
- 动词型：`ЗАРЯЖАЕТ БЫСТРО` / `НЕ СКАНИТ ПОЛ` / `УДОБНО ЛЕЖИТ В РУКЕ`

### 类型 F：无字白底产品图

适用：副图末尾，纯产品展示。

**结构：**
- 纯白背景，无任何文字。
- 产品（打开的收纳盒+工具）放在中央，45 度俯视角或微侧。
- 工具整齐嵌在盒内，盒盖打开在左侧或上方。
- 体积感强，工具与盒体关系清晰。
- 让买家看到"我买到的东西长什么样"。

## 不可生成清单（合规硬规则）

继承 `ozon-general-layouts.md` 和 `ozon-cover-layouts.md` 的全部禁止项，特别注意：

- **不要价格、不要折扣、不要评分星星、不要爱心收藏**。
- **不要 Ozon 标识、不要二维码、不要联系方式**。
- **不要"ТОП ПРОДАЖ""ХИТ""СКИДКА 50%""ВЫБОР ПОКУПАТЕЛЕЙ"** 等促销贴标签。
- **不要假认证**——只写真实存在的认证（小米生态链产品本身通过 РСТ/ЕАС 的可写"ТОВАР СЕРТИФИЦИРОВАН"；如不确定就不写）。
- **不要医疗功效**——美护类不要写"лечит""избавляет от""гарантирует результат"；只写功能描述（"бережная очистка""для аккуратной работы"）。
- **不要编造数字**——尺寸、重量、数量、容量、功率、马达转速、续航时长等只写用户提供的真实数据。
- **不要写"ЛУЧШИЙ""№1""САМЫЙ"** 等绝对承诺。
- 小米 logo 仅在文字图出现，且需保持原版造型（橙色方块+白字"mi"+黑字"xiaomi"），不要变形。

## 与其他品类规范的关系

1. **先读** `references/ozon-general-layouts.md`——全局字号、比例、平台 UI 红线。
2. **再读** `references/ozon-cover-layouts.md`——封面版式 A/B/C/D/E 选择逻辑。
3. **本文件**——把"小米数码/小米 3C 周边"这一品类的视觉系统（深色主图+橙红渐变标题+红色色块信息卡+灰色细节特写+白底产品图）固定下来。
4. 其他 3C 子品类（电动剃须刀、智能音箱、充电宝、电动牙刷）可继承本文件的"小米品牌色+深色主图+渐变细节特写"组合，但工具陈列（D）和红色色块（B）只适用于小件实物套装。
