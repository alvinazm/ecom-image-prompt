# 1688 详情页默认逻辑

当任务涉及 1688 商品详情页时，默认优先使用本逻辑组织提示词。1688 详情页不是品牌故事页，而是采购说明页：要把商品参数、工艺、用途、批发优势和信任信息讲清楚。

## 核心原则

- 详情页优先解决采购决策，不优先制造品牌情绪。
- 每一屏都要讲一个明确的信息点：卖点、参数、工艺、场景、对比、包装、服务、定制。
- 产品不需要每屏都出现，但必须保持同一商品的视觉锚点和统一风格。
- 详情页必须连续，像同一条长图拆成分屏，而不是每屏都像独立海报。
- 不编造价格、起订量、库存、认证、产能、发货时效。

## 推荐详情页顺序

1. 首屏利益点：一句话说明核心优势。
2. 核心卖点：功能、材质、结构或性能。
3. 规格参数：尺寸、型号、颜色、包装、配件。
4. 工艺细节：做工、接口、纹理、材质近景。
5. 场景应用：适用行业、空间、使用方式。
6. 对比说明：普通款 vs 升级款 / 单件 vs 套装。
7. 服务与信任：工厂实力、发货、定制、售后。
8. 收尾页：再次回到商品和采购动作。

## 详情页连贯性规则

做详情页 4-8 段时，必须先定义一套连续视觉系统，再逐张输出。每张图都要像同一条详情长图里的连续分屏。

连续视觉系统至少包含：
- 统一背景
- 统一主色
- 统一字体风格
- 统一版式组件
- 统一产品锚点
- 统一道具 / 光影
- 统一叙事顺序

生成每张详情图提示词时，必须显式写入：

```text
延续上一屏 / 整套详情页的{背景、主色、字体、卡片、图标、道具、光影、产品锚点}，这是第{N}屏，必须像同一条详情页连续分屏，不要做成独立海报。
```

## 详情页信息层级

- 主标题：一句话讲清楚核心采购利益。
- 副标题：补充卖点或场景。
- 参数条：尺寸、型号、材质、包装、数量等。
- 图标 / 卡片：用简洁组件辅助理解。
- 说明文字：短句、直接、偏功能表达。

## 风格方向建议

1688 详情页常见的可执行方向：

1. 白底参数型：适合工具、配件、标准品。
2. 工厂实力型：适合源头店、批发、定制业务。
3. 批发卖点型：适合爆款、订货页、货源页。
4. 场景应用型：适合家居、服装、日用百货。
5. 对比说明型：适合升级款、套装、差异化商品。

## 默认提示词骨架

```text
生成 1688 商品详情页第{N}屏，比例{3:4/1:1}。

本屏定位：{首屏利益点/核心卖点/规格参数/工艺细节/场景应用/对比说明/服务信任/收尾页}。

产品参考图用于锁定商品外观：{品类、颜色、材质、结构、规格、包装、关键细节}。出现产品时必须保持一致，不要重新设计商品本体。

延续上一屏 / 整套详情页的{背景、主色、字体、卡片、图标、道具、光影、产品锚点}，本屏必须像同一条详情页连续分屏，不要做成独立海报。

画面结构：{商品位置、信息区、参数区、图标区、对比区、服务区等}。

页面文字：
主标题“{短标题}”
副标题“{副标题}”
标签“{3-4 个短卖点或参数}”

要求：真实 1688 商品详情页质感，信息清楚，层级明确；不要做成淘宝式情绪海报；不要编造价格、认证、库存、起订量；无水印。
```

## 服务与信任页内容建议

当详情页需要展示服务能力时，优先表达：

- 工厂生产线
- 仓库货架
- 打包发货
- 质检流程
- 打样定制
- 现货陈列
- 物流装箱

这类页面要真实、专业、可信，不要过度艺术化。
