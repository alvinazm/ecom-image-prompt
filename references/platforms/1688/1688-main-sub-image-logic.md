# 1688 主图/白底图/副图默认逻辑

当任务涉及 1688 批发、工厂、源头店铺的主图、白底图和副图时，默认优先使用本逻辑组织提示词。1688 的图不是品牌种草图，而是采购判断图：要让买家快速看懂卖什么、规格是什么、优势是什么、适不适合拿货。

## 核心原则

- 主图负责第一眼识别：商品是什么、规格是什么、优势是什么。
- 白底图负责标准化展示：颜色准确、结构清晰、适合上架和铺货。
- 副图负责承接采购疑问：材质、尺寸、型号、套装内容、用途、工艺、对比、可定制点。
- 图片优先讲清楚“货”，而不是讲情绪、氛围或品牌故事。
- 不要把 1688 图做成淘宝/Shopify 式生活方式海报。
- 不编造价格、起订量、库存、认证、产能、发货时效。

## 默认素材结构

主图 1 张 + 白底图 1-3 张 + 副图 4-6 张时，优先按下面顺序：

1. 主图：商品整体 + 核心卖点 + 采购语境。
2. 白底图 1：正面标准展示，适合上架。
3. 白底图 2：侧面/背面/多件组合或包装展示。
4. 副图 1：核心卖点页，讲最强优势。
5. 副图 2：材质/工艺/结构页，讲为什么有优势。
6. 副图 3：规格/尺寸/型号页，讲怎么买。
7. 副图 4：场景/用途页，讲适合谁用。
8. 副图 5：对比页，讲升级点。
9. 副图 6：包装/配件/套装页，讲发货内容。

## 画面变化要求

每张图都必须显式写出本图与上一张不同的信息任务：

- 信息变化：主卖点、规格、材质、工艺、场景、对比、包装、定制。
- 视角变化：正面、侧面、背面、俯视、局部特写、组合展示。
- 构图变化：单品居中、组合排布、参数分栏、局部放大、对比并列。
- 视觉变化：白底、浅灰、工厂环境、功能场景、信息卡片。

避免写成“同一个商品换几张好看的图”这种空泛提示。每张副图都要有明确采购任务。

## 案例风格反推示例

如果用户给出一组“主图大主体 + 白底标准图 + 参数说明图 + 对比卖点图”的参考图，可反推为：

- 风格：1688 批发标准图，偏采购说明。
- 模特/主体：商品主体优先，人物不是必须项；只有服装类或必须演示使用方式时才加模特。
- 场景：白底、浅灰台面、工厂环境、参数信息卡、组合陈列。
- 道具：尺子、卡尺、包装盒、配件、工厂货架、物流箱，作为信息辅助，不抢主体。
- 构图：主图居中大主体，副图用参数卡、分栏、局部放大、对比排布。
- 禁止照抄：不要复制参考图里的品牌标识、价格、认证编号、原文案和商品主体；只保留信息层级和拍摄逻辑。
