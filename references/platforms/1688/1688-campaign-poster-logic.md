# 1688 活动图默认逻辑

当任务涉及 1688 上新图、促销图、订货会图、清仓图、平台招商活动图时，默认优先使用本逻辑组织提示词。1688 活动图服务于批量采购、引流和订货，不是品牌情绪海报。

## 核心原则

- 活动主题必须明确：上新、清仓、订货会、大促、平台招商、季度备货等。
- 产品必须是第一视觉焦点，不能让活动装饰抢主体。
- 价格、优惠、满减、赠品、起订量、包邮等必须来自用户，不得编造。
- 画面要有批发感、上新感、订货感或工厂活动感。
- 不要做成淘宝式强情绪种草，也不要做成 Shopify 式极简品牌广告。

## 常见活动方向

1. 新品上新
2. 批发热卖
3. 清仓出货
4. 订货会 / 招商会
5. 店铺活动
6. 节日促销
7. 工厂直供活动
8. 季度备货 / 开年备货

## 画面内容建议

- 主标题：活动主题直接表达。
- 副标题：补充产品类型或采购利益。
- 标签：批发、现货、定制、上新、热卖等短词。
- 视觉元素：货架、纸箱、打包台、爆款标签、倒计时感、活动氛围。
- 产品占比：必须作为第一视觉焦点。

## 默认提示词骨架

```text
生成 1688 活动海报，比例{1:1/3:4/9:16/16:9}。

活动主题为“{主题}”，产品为{品类、颜色、材质、规格、关键卖点}，产品作为第一视觉焦点，适合 1688 批发 / 采购 / 订货场景。

画面风格：{上新 / 批发热卖 / 清仓 / 工厂直供 / 订货会 / 节日促销}，加入{活动氛围元素}，整体清晰、有批发感、有信息层级。

页面文案：
主标题“{标题}”
副标题“{副标题}”
角标“{活动标签}”

要求：真实电商活动图质感，商品主体清晰，不要编造价格、优惠、赠品、起订量；无水印。
```

## 活动图注意事项

- 如果没有活动主题，不要硬做“促销感”，可以先做上新或批发卖点图。
- 如果没有价格和优惠信息，用“限时上新”“批量订货”“工厂直供”这类概括性表达。
- 活动图仍然要符合 1688 采购逻辑，不能只追求热闹。
