# 1688 工厂实力 / 定制 / 包装发货默认逻辑

当任务涉及 1688 工厂图、实力图、定制图、包装图、发货图时，默认优先使用本逻辑组织提示词。1688 用户非常在意供货稳定性、工厂能力和交付效率，所以这类图是 1688 的核心信任素材。

## 核心原则

- 重点是真实、专业、可信，不要做成品牌广告海报。
- 画面要让买家感到“这家能供货、能做货、能交付”。
- 可展示生产线、仓库、质检、打包、打样、定制、装箱、物流。
- 不要编造产能、认证、库存、发货时效、合作客户、销量数据。
- 不要把工厂图做成淘宝式生活方式场景或 Shopify 式高级品牌片。

## 默认图类型

1. 工厂生产线
2. 仓库货架 / 现货陈列
3. 打包发货
4. 质检流程
5. 打样 / 定制
6. 包装盒 / 装箱
7. 物流发货 / 装车

## 画面内容建议

### 工厂生产线
- 机器设备
- 工人操作
- 原材料 / 半成品
- 生产流程感
- 车间秩序感

### 仓库货架 / 现货陈列
- 大量整齐货品
- SKU 分类
- 纸箱 / 托盘 / 货架
- 源头供应感

### 打包发货
- 封箱胶带
- 包装台
- 面单
- 装箱动作
- 批量发货氛围

### 质检流程
- 检查台
- 测量工具
- 抽检动作
- 记录表 / 标签
- 专业可信的作业感

### 打样 / 定制
- 打样台
- 样品对比
- 颜色卡 / 材质卡
- 定制沟通板
- 可变规格展示
