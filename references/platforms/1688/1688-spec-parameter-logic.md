# 1688 规格参数 / 工艺细节默认逻辑

当任务涉及 1688 规格图、参数图、工艺图、结构图时，默认优先使用本逻辑组织提示词。1688 采购用户很看重参数是否清楚、结构是否真实、工艺是否能看懂。

## 核心原则

- 规格图是为了让买家快速判断是否适配，不是为了做海报感。
- 参数必须来自用户提供的信息或产品实物，不要默认编造。
- 工艺细节要真实，尽量展示材质、接口、纹理、结构、边角、内里、配件。
- 信息层级要清楚：标题 > 参数点 > 说明文字 > 辅助图示。
- 不要把规格图做成花哨拼贴，避免干扰读取。

## 常见内容模块

1. 尺寸示意
2. 材质说明
3. 型号区分
4. 配件组成
5. 包装内容
6. 适配范围
7. 工艺细节
8. 结构分解
9. 多规格对比

## 规格图表现方式

### 尺寸示意
- 使用清晰测量线、标尺、参数框。
- 需要明确长、宽、高、直径、厚度、重量等。
- 如果用户没给具体数值，不要自己编数字。

### 材质说明
- 展示纹理、截面、纤维、金属、塑料、布料、板材等质感。
- 用局部放大、切片、剖面、纹理卡辅助表达。

### 型号区分
- 多个型号并排展示。
- 颜色、接口、尺寸、配置区分清楚。
- 适合同款不同规格、不同配件的商品。

### 配件组成 / 包装内容
- 把主件、配件、说明书、包装盒、赠件分开陈列。
- 适合套装、组合装、工具包、电子配件。

## 使用注意

- 如果产品属于工具、电子配件、工业品、包装材料等，规格图优先级更高。
- 如果用户提供了图纸、参数表、尺码表，可以直接转成信息图风格。
- 如果用户没有具体参数，只能做“结构示意 / 规格区间 / 图示说明”，不能乱写数值。
