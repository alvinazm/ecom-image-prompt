# 化妆品详情页默认逻辑

当任务涉及化妆品、护肤品、美妆个护类详情页时，默认优先使用本逻辑组织详情页提示词。适用品类包括面霜、精华、乳液、面膜、洁面、防晒、祛斑霜、美白霜、抗皱霜、身体护理等。

## 默认推荐详情页风格

化妆品/护肤品/美妆个护类详情页默认优先推荐“包装色系高级棚拍 + 成分/肤感/质地信息分屏 + 首尾产品强召回”的连续详情页风格。给客户确认风格时可以提供多个选项，但要建议客户优先选择这套；客户没有特别指定其他风格时，默认按这套执行。

推荐选择文案：

```markdown
这类化妆品详情页我建议优先选第 1 套：
1. 包装色系高级棚拍风（推荐）：第 1 屏和第 7 屏完整展示产品，中间屏按问题、成分、肤感、质地、包装信息展开，色调跟随产品包装，整套像一条连续详情长图。
2. 轻植物成分风：适合草本、植萃、自然护肤定位。
3. 科技功效信息风：适合成分党、功效型、需要机制图表达的产品。
4. 生活梳妆台场景风：适合日常护肤、年轻化、使用感表达。
```

## 核心原则

- 详情页不是简单罗列卖点，而是按购买决策顺序组织：问题 -> 机制 -> 成分 -> 使用感 -> 信任背书 -> 质地 -> 产品展示。
- 产品图用于锁定真实包装外观、品牌、备案号、规格、瓶型、盒型、颜色和标签版式。包装上的关键信息不能随意改写、删除或重新设计。
- 色调必须跟随产品包装。如果产品是白金包装，详情页默认使用珍珠白、香槟金、浅金、少量黑金线条；如果产品是绿白包装，才使用浅绿植物风；不要只因为参考图是绿色就把所有产品做成绿色。
- 产品不需要每一屏都强行出现。开场、资质背书、质地弱露出、产品展示收尾可以出现产品；机制、成分、肤感页可以弱化或不出现产品。
- 参考图只用于学习详情页结构、构图、信息层级和氛围，不能照抄参考图的品牌、产品主体、文案、价格、证书、活动信息。
- 不编造价格、销量、优惠、赠品、资质编号、检测编号、认证结论。用户没给具体信息时，只能用概括性表达。
- 避免医疗化和绝对化表达：不要写治疗、根治、永久、最强、全网第一、医美级、药效等。

## 默认 7 屏详情页结构

### 第 1 屏：主视觉开场

目标：建立商品记忆和核心利益点。

- 产品完整出现，优先展示罐、瓶、盒、套装等真实包装。
- 标题表达核心利益点，例如“净白焕颜亮肤”“美白抗皱紧致”“透亮细腻肌”。
- 可加入 3 个肌肤问题卡片，例如紫外线影响、环境污染、熬夜暗沉、干纹细纹、肤色不均。

### 第 2 屏：水润/亮肤机制

目标：把功效感做成可视化机制。

- 产品可以不出现。
- 画面可用水波、精华液滴、玻璃涟漪、光感粒子、肌肤透亮路径。
- 信息点控制在 3-4 个，例如焕白肌肤、改善暗黄、保湿锁水、水润弹嫩。

### 第 3 屏：成分路径解析

目标：解释为什么值得买。

- 产品通常不出现，重点做成分科技剖面图、肌肤层、活性粒子、分子线条。
- 可按“表层提亮 / 中层阻黑 / 底层养护”或“清洁 / 修护 / 锁水”组织。
- 成分表达必须谨慎。可以写“烟酰胺协同亮肤”“377亮肤因子”“VC焕亮灵感”，不要写成医疗治疗效果。

### 第 4 屏：上脸肤感/使用场景

目标：让用户感受到质地、肤感和日常使用场景。

- 产品可不出现，或只在角落弱露出。
- 适合女性侧脸、手部涂抹、梳妆台护肤、膏体上脸。
- 不做夸张前后对比，不要过度磨皮。

### 第 5 屏：资质/信任背书

目标：建立信任。

- 如果产品包装有国妆特字、备案号、检测信息、专利号等，必须以产品图或用户提供信息为准。
- 可做证书风格文件、放大镜、红色印章、金色标注线，但不要伪造完整真实证书细节。
- 建议加提醒：“特证信息以产品包装标识为准”。

### 第 6 屏：质地展示

目标：解决用户对肤感的疑问。

- 产品小露出即可，主画面重点展示膏霜、乳液、精华、泡沫、膜布等质地。
- 画面语言根据品类选择：奶霜质地、清透啫喱、水感精华、绵密泡沫、柔软膜布。
- 文案突出“细腻、润而不黏、清爽、好推开、日常好吸收”等，不要夸张功效。

### 第 7 屏：产品展示收尾

目标：回到实物，完成购买闭环。

- 产品完整展示，包装外观和关键信息要尽量清晰。
- 可以使用展台、玻璃球、水滴、少量花瓣/植物、香槟金线条等道具。
- 信息点可写规格、瓶罐质感、盒装、日常护肤等。

## 产品一致性锁定清单

生成提示词时，如果用户给了产品图，必须显式写入：

- 品牌名、产品名、备案号/特证号、规格净含量。
- 瓶型、盖子颜色、瓶身颜色、盒型、标签位置、侧标、底栏、图案。
- 哪些包装文字必须保留，哪些页面文案可以扩展。
- 产品出现的屏数和强弱：第 1 屏完整出现，第 5 屏用于资质背书，第 6 屏弱露出，第 7 屏完整收尾；第 2-4 屏不强行放产品。

```text
页面文字：

副标题“{副标题}”
信息点“{3-4个短卖点}”

要求：真实淘宝美妆详情页质感，中文尽量清晰端正，视觉与前后屏连贯；不要价格、销量、赠品；不要治疗、根治、永久、最强等绝对化表述；无水印。
```
