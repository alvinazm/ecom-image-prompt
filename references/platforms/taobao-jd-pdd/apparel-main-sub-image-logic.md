# 服装主图/副图默认逻辑

当任务涉及女装、男装、童装、鞋包配饰、户外服饰等服装类主图和副图时，默认优先使用本逻辑组织提示词。主图/副图本质是一组商品相册：围绕同一件衣服，用不同角度、不同景别、不同动作展示上身效果、版型、面料、细节和穿搭场景。

## 核心原则

- 主图负责第一眼点击：模特上身、商品完整清晰、风格明确，用户一眼知道卖什么。
- 副图负责承接相册浏览：不能只是换一张类似照片，要按正面、侧面、背面、半身、细节、场景动作逐张变化。
- 服装类主副图默认带模特和场景。除非用户明确要求白底图、平铺图、无模特图，否则不要只做空衣服或纯棚拍。
- 用户没有提供模特信息时，必须根据服装风格补一个合理模特设定；用户没有提供场景时，必须根据季节、版型、价格带和参考图风格补一个合理拍摄场景。
- 同一组主副图要像一次真实拍摄产出的相册：同一位模特、同一套妆发气质、同一件衣服、同一组核心搭配、同一套色调和光线。
- 可以更换同一地点内的机位或从室外走到相邻室内，但不要每张图都跳到完全不同世界观。
- 参考图只学习拍摄逻辑、模特动作、景别、光线、场景气质和穿搭氛围，不复制原模特身份、原品牌、原文案、原店铺标识、原商品主体。

## 缺省补全规则

### 没有模特信息时

根据服装自动补全，不要停下来反复询问：

- 女装：默认亚洲女性模特，20-30 岁，自然清透妆容，干净发型，身形匀称，气质贴合风格。
- 男装：默认亚洲男性模特，20-35 岁，干净自然造型，身形挺拔，气质贴合通勤、户外或休闲定位。
- 童装：默认对应年龄段儿童模特，动作自然可爱，画面安全、明亮、亲和。
- 中性/无法判断性别：默认选择最贴合商品版型和目标消费人群的模特；若仍不清楚，用“亚洲模特，中性自然穿搭气质”。
- 不要指定真实明星、网红或参考图人物身份；只描述年龄段、气质、妆发、姿态。

### 没有场景说明时

根据衣服风格补一个淘宝服装常用场景：

- 韩系温柔/甜美/日常女装：咖啡店门口、灰水泥墙、绿植、石子路、自然光街角、简洁室内咖啡空间。
- 通勤/简约/高级感：浅灰街区、现代办公楼外、极简室内、干净白墙、自然窗光。
- 轻户外/旅行/防晒衣：公园步道、海边栈道、城市绿道、露营草地、阳光街角。
- 运动/机能/冲锋衣：城市户外、山野步道、运动场、骑行路段，光线清晰有速度感。
- 家居/睡衣/内搭：明亮卧室、软装客厅、窗边、浅色床品或沙发。

如果用户给了参考图但没写场景，优先从参考图中提炼场景气质。例如案例图可反推为“韩系轻户外咖啡店门口，自然光，水泥墙、绿植、石子路、手持咖啡、草编包，轻松生活感”。

## 默认相册结构

主图 1 张 + 副图 4-6 张时，优先按下面顺序：

1. 主图：正面或 3/4 正面全身/膝上构图，模特上身完整展示，商品是第一视觉焦点。
2. 副图 1：全身正面或走动姿势，展示整体穿搭比例、长度、廓形。
3. 副图 2：3/4 侧面或侧身回头，展示衣服宽松度、垂感、袖型、肩线。
4. 副图 3：背面或转身角度，展示后片、下摆、整体版型。
5. 副图 4：半身近景，展示领口、纽扣、抽绳、刺绣、图案、面料纹理等细节。
6. 副图 5：场景动作图，坐下、走路、拿咖啡、提包、扶帽子、整理衣摆等，强调真实穿着感。
7. 副图 6：可选信息图或 SKU 承接，展示多色、尺码、面料卖点；只有用户给了数据时才写具体尺码和参数。

如果用户只要 4 张副图，保留“整体正面、侧面/3/4、细节近景、场景动作”。如果用户要更多副图，再扩展背面、搭配、面料、尺码、多色。

## 画面变化要求

每张图都必须显式写出本图与上一张不同的拍摄点：

- 角度变化：正面、3/4、侧面、背面、俯一点、低一点。
- 景别变化：全身、膝上、半身、胸上、局部特写。
- 动作变化：站立、走动、回头、抬手整理头发、手持杯子、提包、插兜、扶帽檐。
- 信息变化：版型、面料、细节、穿搭、场景、尺码或多色。

避免写成“同一模特同一场景拍几张好看的图”这种空泛提示。每张副图都要有明确任务。

## 主图提示词骨架

```text
生成淘宝服装主图，比例1:1或3:4。产品为{服装品类、颜色、面料、版型、关键细节}。{模特设定}穿着展示，{场景设定}，自然真实服装摄影质感。

构图：模特正面或3/4正面，商品完整清晰，主体占画面65%-80%，衣服版型、颜色、面料纹理和关键细节准确，背景有生活感但不抢主体。

画面风格：{韩系温柔/轻户外旅行/通勤简约/高级棚拍/运动机能等}，光线{自然光/柔和窗光/清爽日光}，色调与商品颜色协调。

要求：无文字、无水印、无夸张滤镜，不改变衣服版型和颜色，不复制参考图人物身份、品牌标识或店铺标识。
```

## 副图提示词骨架

```text
生成淘宝服装副图第{N}张，比例1:1或3:4。本图任务：{整体版型/侧面廓形/背面展示/面料细节/领口袖口细节/场景穿搭/尺码信息/多色展示}。

产品保持一致：{服装品类、颜色、面料、版型、关键细节}，与主图同一件衣服，同一位{模特设定}，延续同一套{场景设定、光线、色调、搭配道具}。

画面变化：本图采用{角度}、{景别}、{动作}，重点展示{本图信息点}，不要与主图重复同一姿势。

要求：真实淘宝服装相册摄影，商品清晰无遮挡，版型准确，颜色稳定，无水印。只有用户提供尺码、参数、活动信息时才生成具体文字；否则默认无文字。
```

## 案例风格反推示例

用户给出类似“奶油黄色刺绣上衣 + 焦糖短裤 + 咖啡店门口/水泥墙/绿植/石子路”的参考图时，可反推为：

- 风格：韩系温柔轻户外穿搭，生活感街拍。
- 模特：亚洲女性，20-30 岁，自然妆容，长卷发或自然发型，亲和清爽。
- 场景：咖啡店门口、灰水泥墙、绿植、石子路、自然日光，也可扩展到相邻室内咖啡空间。
- 道具：手持咖啡杯、草编包、简洁凉鞋，作为穿搭氛围，不抢衣服主体。
- 构图：主图正面/3/4 膝上或全身，副图用全身走动、侧身、半身近景、整理头发、手持咖啡等变化。
- 禁止照抄：不要复制参考图里的文字牌、店铺标识、人物长相和原商品细节；只保留拍摄逻辑和氛围。
