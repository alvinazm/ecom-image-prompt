# 化妆品主图/副图默认逻辑

当任务涉及化妆品、护肤品、美妆个护类主图和副图时，默认优先使用本逻辑组织提示词。主图负责点击，副图负责承接点击后的核心疑问，不能把主图、副图都做成同一种画面。

## 默认推荐套图风格

化妆品/护肤品/美妆个护类默认优先推荐“包装色系高级棚拍 + 成分/肤感/质地信息分屏 + 首尾产品强召回”的套图风格。给客户确认风格时可以提供多个选项，但要建议客户优先选择这套；客户没有特别指定其他风格时，默认按这套执行。

推荐选择文案：

```markdown
这类化妆品我建议优先选第 1 套，整体更适合淘宝/抖音通用转化：
1. 包装色系高级棚拍风（推荐）：主图和尾图完整展示产品，中间副图不强行放完整产品，分别讲成分、肤感、质地、包装信息，色调跟随产品包装。
2. 轻植物成分风：适合草本、植萃、自然护肤定位。
3. 科技功效信息风：适合成分党、功效型、需要机制图表达的产品。
4. 生活梳妆台场景风：适合日常护肤、年轻化、使用感表达。
```

## 核心原则

- 主图只抓最强点击理由：产品大主体、强利益标题、1 个高记忆卖点、1 个转化标签。
- 副图按“配方成分 -> 功效机制/肤感反馈 -> 资质背书 -> 质地/使用方式 -> 产品展示/规格”的顺序承接。
- 默认不要让每张副图都带完整产品。主图和最后一张产品展示/规格图强展示产品；中间副图以成分、机制、肤感、质地、包装局部为主。包装信息页可以局部露出包装，但不要做成第二张主图。
- 色调必须跟随产品包装。白金包装默认白金轻奢，绿白包装才用植物清透，粉色包装可用柔粉肤感，不要机械套参考图色调。
- 产品图用于锁定包装外观、品牌、产品名、备案号/特证号、净含量、瓶型、盒型、标签版式。所有出现产品的画面都必须保持一致。
- 参考图只能学习构图、信息层级、卖点组织和氛围，不能照抄品牌、产品、价格、具体数值、证书、真实反馈图。
- 不编造具体浓度、百分比、天数、实验数据、用户反馈、检测报告、认证编号、销售数据。用户没提供时，用概括性表达。
- 避免医疗化和绝对化表达：不要写治疗、根治、永久、最强、全网第一、药效、医美级等。

## 默认主图逻辑

主图建议 1:1，用于搜索结果、推荐流和商品卡首图。

### 画面结构

- 产品大近景，主体占画面 55%-75%。
- 可用开盖膏体、精华质地、瓶罐高光、包装局部放大增强质感。
- 背景跟随包装主色，使用高对比但干净的电商广告构图。
- 标题要短、强、清楚，通常 1 句大利益点。
- 可加入 1 个转化标签，例如“现货速发”“大牌同款风格”“店铺热推”。具体活动、价格、赠品必须由用户提供。

### 主图可用信息层级

1. 品牌或产品名。
2. 核心利益标题，例如“一瓶攻克多重斑点 重塑美丽”“美白抗皱 紧致淡斑”。
3. 高记忆卖点，例如“玻色因浓度感”“双效美白抗皱配方”“国妆特证美白”。具体浓度和数字必须来自用户。
4. 转化标签，例如“现货速发”“支持代发”“铺货上新”。

## 默认副图逻辑

副图建议 4-6 张，比例 1:1 或 3:4。每张只讲一个核心信息点。

### 副图 1：配方成分

目标：告诉用户为什么有卖点。

- 画面可使用金色精华球、分子胶囊、肌肤层、成分流动路径。
- 常见结构：大标题 + 副标题 + 3 个成分标签。
- 成分文案要保守，例如“烟酰胺：提亮肤色、细腻肤感”“377：亮肤灵感”“a-熊果苷：匀净肤色”。不要写药效和治疗。

### 副图 2：功效机制/肤感反馈

目标：承接用户对效果的期待。

- 默认使用“肤感观察”“使用感反馈”“亮肤路径”这类低风险表达。
- 不默认生成 Before/After 前后对比，不默认写“7 天焕亮、15 天透白、28 天淡斑”等具体周期。
- 如果用户明确提供真实测试数据和图片素材，才可以按用户数据做反馈页，并注明数据来源于用户提供。

### 副图 3：资质背书

目标：建立信任。

- 如果产品有国妆特字、备案号、检测报告、专利号等，必须以用户产品图或用户文字为准。
- 可用证书风格文件、放大镜、红章、金色标注线，但不要伪造完整证书内容。
- 建议突出产品包装上的真实编号，并加“资质信息以产品包装标识为准”。

### 副图 4：质地展示

目标：解决是否好用、黏不黏、好不好吸收。

- 画面可用膏体开盖、乳霜抹开、精华滴落、泡沫质地、膜布纹理。
- 文案可写“奶霜质地”“润而不黏”“细腻好推开”“日常护肤好吸收”。

### 副图 5：产品展示/规格

目标：回到实物和购买信息。

- 展示瓶罐、外盒、侧标、净含量、套装内容、规格。
- 包装文字尽量清晰，保持和产品图一致。

## 风险表达处理

- 具体数字：如“99.999%”“7 天”“15 天”“28 天”“浓度 xx%”必须由用户提供，不得默认编造。
- 前后对比：默认不生成真实人脸 Before/After 对比，除非用户提供真实素材和授权语境。
- 资质证书：可做背书氛围，但不能编完整证书编号、检测结论、机构名称。
- 功效词：美白、祛斑、抗皱、紧致等以产品包装和用户提供信息为准；表达时优先使用“帮助、改善、淡化、提亮、日常护理”。

## 默认提示词骨架

```text
生成淘宝/抖音护肤品{主图/副图第N张}，比例{1:1/3:4}。

本图定位：{强点击主图/配方成分/功效机制/资质背书/质地展示/产品规格}。

产品参考图用于锁定包装外观：{品牌、产品名、瓶型、盒型、颜色、标签、备案号/特证号、净含量}。出现产品时必须保持一致，不要重新设计包装。

整体色调：跟随产品包装，主色为{产品主色}，搭配{辅助色和光影}。

画面结构：{产品位置、信息卡片、成分球、证书、膏体、人物/肌肤场景等}。

页面文字：
主标题“{短标题}”
副标题“{副标题}”
标签“{3-4个短卖点}”

要求：真实淘宝美妆电商图质感，中文尽量清晰端正，产品和包装信息准确；不要编造价格、销量、赠品、具体浓度、具体测试周期、证书编号；不要治疗、根治、永久、最强等绝对化表述；无水印。
```
