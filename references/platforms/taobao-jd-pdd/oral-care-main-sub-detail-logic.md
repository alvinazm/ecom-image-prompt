# 口腔护理行业淘宝素材规则

当任务涉及口腔护理类目（牙膏、漱口水、牙刷、牙线、口腔护理套装等）时，默认优先使用本逻辑组织提示词。口腔护理是强功效、强信任、强合规的类目，素材必须在“吸引点击”和“合规表达”之间找平衡。

## 适用品类

- **牙膏**：普通清洁牙膏、美白牙膏、抗敏感牙膏、防蛀牙膏、儿童牙膏、功效型牙膏（溶菌酶、益生菌、中草药等）
- **漱口水**：便携装、家庭装、功效型漱口水
- **牙刷/牙具**：手动牙刷、电动牙刷、冲牙器、牙线棒、舌苔刷
- **口腔护理套装**：牙膏+牙刷+漱口水组合、家庭装、礼盒装

## 行业特殊性（必须先知道）

1. **牙膏按化妆品管理**：2022 年起《牙膏监督管理办法》实施，牙膏功效宣称必须有充分科学依据，备案信息以产品包装为准。
2. **功效宣称受限**：美白、抗敏感、防龋、抑制牙菌斑、减轻牙龈问题等属于功效宣称，不能随意编造，必须以产品包装标识或用户提供的检测报告为准。
3. **禁止医疗化表达**：不得使用“治疗、治愈、根治、消炎、杀菌、药效、医用级、口腔科医生专用”等词汇。
4. **儿童牙膏有额外红线**：不得宣传“可吞咽”“可食用”“食品级”，不得暗示儿童可以吞食。
5. **检测报告不能伪造**：功效报告、人体试验、检测机构、数据百分比、样本量必须由用户提供或来自真实包装，不能凭空生成。

## 默认推荐套图风格

口腔护理类默认优先推荐 **“医疗信任感 + 功效信息分屏 + 产品强召回”** 的套图风格。给客户确认风格时可提供多个选项，但建议优先选择这套；客户没有特别指定其他风格时，默认按这套执行。

推荐选择文案：

```markdown
这类口腔护理产品我建议优先选第 1 套，转化和信任感更完整：
1. 医疗信任功效风（推荐）：主图强展示产品矩阵，副图按痛点、成分、机制、检测报告、质地展开，色调以白、青绿、浅蓝、香槟金为主，建立专业可信感。
2. 清新日常护理风：明亮浅蓝/薄荷绿/水果色，适合日常清洁、口气清新、年轻家庭场景。
3. 高端极简功效风：黑白金/白金色系，适合进口线、高端抗敏感、轻奢定位。
4. 节日促销礼盒风：红金/红包/礼盒，适合大促、家庭装、送礼场景，但主图仍需保留产品清晰度。
```

## 核心原则

- **主图只抓最强点击理由**：产品主体、强功效标题、1 个核心记忆点、1 个转化标签。
- **副图按“痛点共鸣 -> 问题成因 -> 功效机制 -> 成分/技术 -> 资质背书 -> 质地/使用方式 -> SKU 规格”的顺序承接。**
- **默认不要让每张副图都带完整产品**：主图和最后一张 SKU/规格图强展示产品；中间副图以痛点场景、机制图、检测报告、质地为主。
- **色调跟随产品包装和功效定位**：
  - 功效型/医用感产品：白色、青绿色、浅蓝色、香槟金、少量深绿/深蓝线条
  - 清新口气/日常护理：薄荷绿、天蓝、浅橙、果味色系
  - 高端抗敏感/进口线：珍珠白、香槟金、黑金、极简灰
  - 大促/礼盒：红色、金色、暖橙（仅用于活动图，不替代主图产品展示）
- **产品图用于锁定包装外观、品牌、产品名、备案号、净含量、管型、标签版式、功效编号**。所有出现产品的画面都必须保持一致。
- **参考图只能学习构图、信息层级、卖点组织和氛围，不能照抄品牌、产品、价格、具体数值、证书、真实反馈图。**
- **不编造具体浓度、百分比、天数、实验数据、用户反馈、检测报告、认证编号、销售数据、价格、赠品、销量**。用户没提供时，用概括性表达。
- **避免医疗化和绝对化表达**：不要写治疗、根治、永久、最强、全网第一、药效、医用级、杀菌、消炎等。

## 默认主图逻辑

主图建议 1:1，用于搜索结果、推荐流和商品卡首图。

### 画面结构

- **产品主体占比 55%-75%**，优先展示产品矩阵或核心单品。
- 如果是多 SKU 功效矩阵，主图可展示“产品家族”排列，用编号或颜色区分功效。
- 背景推荐：浅白、青绿渐变、浅蓝渐变、香槟金、或干净的产品色系背景。
- 标题要短、强、清楚，通常 1 句大利益点，例如“一管一功效 专效护齿”“专利配方 牙菌斑减少看得见”。
- 可加入 1 个转化标签，例如“官方直营”“正品保证”“买贵包赔”“国家发明专利”。具体活动、价格、赠品必须由用户提供。
- 功效型产品可加入轻度“实验室/医疗感”元素（试管、分子结构、牙齿剖面、检测报告角标），但不要做成药品广告。

### 主图可用信息层级

1. 品牌或产品名。
2. 核心利益标题，例如“一管一功效 专效护齿”“生物溶菌酶牙膏”“专利配方 护龈固齿”。
3. 高记忆卖点，例如“牙菌斑减少看得见”“国家发明专利”“广药一医人体功效验证”。具体信息必须来自用户。
4. 转化标签，例如“官方直营”“正品保证”“现货速发”。

## 默认副图逻辑

副图建议 4-6 张，比例 1:1 或 3:4。每张只讲一个核心信息点。

### 副图 1：痛点共鸣

目标：让用户觉得“这说的就是我”。

- 画面可使用真实人物局部（嘴部、刷牙动作、捂嘴表情）或问题图标化表达（口腔异味、牙黄、龋齿、牙龈红肿、牙渍）。
- 常见结构：大标题 + 4 宫格痛点场景。
- 文案要克制，例如“口腔异味”“牙黄牙渍”“龋齿困扰”“口腔卫生不良”。不要写成病症诊断。

### 副图 2：问题成因 / 功效机制

目标：解释为什么会产生这些问题，以及产品如何介入。

- 画面可用牙齿剖面、牙菌斑示意图、口腔细菌可视化、食物残渣堆积、分子作用路径。
- 常见结构：问题成因图解 + 产品作用机制。
- 文案优先使用“帮助减少牙菌斑”“帮助维护口腔清洁”“帮助改善口腔环境”等低风险表达。

### 副图 3：核心成分 / 技术

目标：解释为什么值得买。

- 画面可使用成分分子、益生菌、溶菌酶、氟化物、草本精华、矿物颗粒等可视化元素。
- 常见结构：大标题 + 3 个成分标签。
- 成分文案要保守，例如“生物溶菌酶：帮助减少口腔有害菌”“氟化钠：帮助预防龋齿”“益生菌：帮助平衡口腔菌群”。不要写药效和治疗。

### 副图 4：资质背书 / 检测报告

目标：建立信任。

- 如果产品有国家发明专利、功效报告、人体试验报告、备案号等，必须以用户产品图或用户文字为准。
- 可用证书风格文件、放大镜、红章、金色标注线、数据图表，但不要伪造完整证书内容。
- 建议突出产品包装上的真实编号，并加“资质信息以产品包装标识为准”。

### 副图 5：质地 / 使用方式

目标：解决好不好用、膏体什么样、泡沫多不多。

- 画面可用牙膏挤出、牙刷蘸取、刷牙泡沫、膏体特写、漱口水倾倒、冲牙器水流。
- 文案可写“细腻膏体”“低泡温和”“清新薄荷香”“易漱口不刺激”。

### 副图 6：产品展示 / SKU 规格

目标：回到实物和购买信息。

- 展示产品家族、不同编号/颜色 SKU、单支规格、套装内容、净含量。
- 包装文字尽量清晰，保持和产品图一致。

## 默认详情页逻辑

详情页不是副图放大版，要按购买决策顺序组织。常用 7 屏结构：

1. **首屏利益点**：产品家族 + 核心卖点 + 强标题。
2. **痛点场景**：口腔异味、牙黄、龋齿、口腔卫生不良等共鸣画面。
3. **问题成因**：牙菌斑堆积、食物残渣、细菌滋生等可视化图解。
4. **功效机制 / 成分解析**：溶菌酶、益生菌、氟化物、草本等成分作用路径。
5. **资质背书**：人体功效报告、发明专利、检测报告、备案信息。
6. **质地 / 使用方式**：膏体、泡沫、刷牙场景、使用步骤。
7. **产品展示 / SKU 收尾**：完整产品、规格、套装、购买理由。

### 详情页连贯性规则

做详情页 6-8 段或 1-7 屏时，必须先定义一套“连续详情页视觉系统”，再逐张输出。每张图都要像同一条详情长图里的连续分屏，而不是单独成立的海报。

连续详情页视觉系统至少包含：

- **统一背景**：例如浅白实验室台面、青绿渐变、浅蓝渐变、香槟金展台。
- **统一主色**：主色、辅助色、字体色、强调色要贯穿全套。
- **统一版式组件**：标题区、圆角卡片、卖点标签、线性图标、分割线、放大框、数据图表样式等要重复使用。
- **统一产品锚点**：核心商品必须反复出现，角度可以变化，但外观、颜色、结构、包装不能漂移。
- **统一道具和光影**：牙齿模型、牙刷、分子球、检测报告、证书、水杯等道具可以递进增加，但要来自同一个场景体系；光线方向和质感要稳定。
- **统一文字气质**：标题字号、字体风格、语气和信息密度要一致。
- **统一叙事顺序**：首屏利益点 -> 痛点 -> 成因 -> 机制/成分 -> 背书 -> 质地/使用 -> 收尾购买理由。

生成每张详情页提示词时，必须显式写入：

```text
延续上一屏/整套详情页的背景、主色、字体、卡片、图标、道具、光影、产品锚点，这是第{N}屏，必须像同一条详情页连续分屏，不要做成独立海报。
```

## 风险表达处理

- **具体数字**：如“99.999%”“7 天”“15 天”“28 天”“减少 77.8%”“样本量 xx 人”必须由用户提供，不得默认编造。
- **前后对比**：默认不生成真实牙齿 Before/After 对比，除非用户提供真实素材和授权语境。可用“牙菌斑示意图对比”替代真实口腔对比。
- **资质证书**：可做背书氛围，但不能编完整证书编号、检测结论、机构名称、受试者数据。
- **功效词**：美白、抗敏感、防龋、抑制牙菌斑、减轻牙龈问题等以产品包装和用户提供信息为准；表达时优先使用“帮助、改善、减少、维护、日常护理”。
- **儿童牙膏**：不得使用“可吞咽”“可食用”“食品级”“宝宝爱吃”等表述；画面不得暗示儿童吞食牙膏。
- **电动牙刷/冲牙器**：不得使用“医疗级”“替代洗牙”“彻底清除牙结石”等过度承诺。

## SKU 图逻辑

- 每个 SKU 至少输出 2 张：白底产品图 + 使用场景/质地展示图。
- 白底图必须干净，1:1，无文字、无道具，清晰展示管身、颜色、编号、净含量。
- 如果是功效矩阵型产品，每个编号 SKU 必须保持同管型、同设计风格，仅替换编号和功效标签。
- 场景图统一光线、道具和角度，便于形成一组。

## 活动海报逻辑

- 节日、大促、上新、家庭装、送礼场景可扩展活动海报。
- 必须有活动主题、产品焦点、核心利益点和氛围元素。
- 价格、优惠券、满减、赠品、限时信息必须来自用户；未提供时不要编造金额。
- 可以直接生成中文活动标题和短利益点。
- 避免绝对化用语，例如“全网最低”“第一”“最好”。
- 活动图不替代主图，主图仍需保留产品清晰度。

## 一句话总结

口腔护理素材的核心是：**用医疗信任感建立点击，用功效逻辑承接转化，用真实资质背书打消顾虑，所有功效和数据必须来自产品本身，绝不为点击率踩合规红线。**
