> 双胞胎分类：在同一 `tea-tool` 大品类下，与 `shopify/tea-tool.md`（Aesop × 野兽派 暗调禅意静物）形成清晰的视觉双轨。本文件是**文人茶室自然光 UGC 路线**——浅色冷灰素墙 + 石质圆形茶台 + 自然光 + 散落茶器，更接近真实茶友的生活感。

## 3. 锁定视觉系统（NON-NEGOTIABLE）

### 3.1 Color Palette

| 角色 | 颜色 | HEX | 用途 |
|---|---|---|---|
| 紫砂主色 | 紫砂红棕 | `#6B3A1A ~ #8B4513` | 产品主体 |
| 背景素墙 | 冷灰亚光 | `#C8C8C8 ~ #B0B0B0` | 9 张主背景，**必现** |
| 石茶台 | 砚石深棕 | `#4A3C28`（磨砂面） | 主锚点，**必现** |
| 木桌 | 浅橡木 | `#C8A878 ~ #B8956A` | 桌面基底 |
| 远景绿植 | 灰绿叶 | `#3F6038`（虚化） | 左上 / 右上虚化点 |
| 青花瓷 | 钴蓝 | `#1B4F8A` | 点缀色 |
| 干莲蓬 / 枯枝 | 暖棕 | `#6B5A4A` | 虚化点缀 |
| 茶宠 / 木盒 | 深色木质 | `#2D1F12` | 远景点缀 |

### 3.2 Lighting

- **自然光 + 微暖（2700K-3000K）**，左上 45° 入射
- **软光**（柔光箱感或窗光），浅景深（f/2-2.8 光圈感）
- 阴影柔和但有方向感
- 紫砂壶身暗部保留温暖反光（不是死黑）
- **严禁**：冷白闪光 / 棚拍硬光 / HDR / 过曝 / 影楼平光

### 3.3 Composition Rules

- 主体居中或 3/4 视角，负空间 30-50%
- 全套 9 张全部浅景深：背景虚化成色块
- **没有手出现**（pure 静物），不需要仪式感的手部动作
- 一切电商文案、价格、Logo、平台 UI、二维码、电话都不出现
- 默认比例 3:4（800×1067）；可换 1:1（800×800）但需重新构图

### 3.4 禁止项（红线条）

- ❌ 玫瑰木 / 暗背景 / Aesop 风格
- ❌ 棚拍硬光 / 冷白闪光 / 影楼平光
- ❌ 模特手 / 手持 / 茶艺表演动作
- ❌ 底款编造（必须用用户提供的真实底款）
- ❌ 壶身乱贴名人名款（如「时大彬」「陈鸣远」「顾景舟」等真实历史名匠，未授权不可用）
- ❌ 把「宜兴紫砂」标识放到非紫砂产品图上
- ❌ 背景虚化里出现真实品牌 Logo（茅台、可口可乐、星巴克等）
- ❌ 红金礼盒 / 喜庆红 / 双喜 / 福字（节日礼盒另议）

### 4.1 9 张叙事结构（为什么要这么排）

```
全景 ←→ 雕花（装饰）
全景 ←→ 壶嘴（局部）
       ↓
全景 ←→ 刻字（装饰）←→ 壶把（局部）←→ 盖钮（细节）
                                ↓
                           底款（细节）
                                ↓
                           茶室全景（场景）
```

- **#1 + #2**：两个角度的全景主图（hero × 2），让买家从左右两侧感受产品的立体感
- **#3 + #4**：壶身工艺（macro × 2），分别承载雕花和刻字两种装饰
- **#5 + #6**：壶嘴壶把（macro × 2），从局部细节看做工精细度
- **#7 + #8**：盖钮俯视 + 底款倒置（macro × 2），证明手工壶的「上下都有讲究」
- **#9**：茶室全景，把整套静物放进真实的茶室空间

### 4.2 Locked Product Orientation Rules

- **#1 hero**：壶嘴朝**左前方**，把朝右后方
- **#2 hero**：壶嘴朝**右前方**，把朝左后方（与 #1 完全对称的镜像，让买家看两侧）
- **#3 #4 #5 #6 macro**：视角允许任何方向，但产品占画面 60-80%，周边虚化
- **#7 topdown**：壶盖顶部正对镜头，壶嘴朝向 12 点钟或 6 点钟方向
- **#8 bottom**：壶底朝上，把朝左上方（不要把朝正上方，会显得呆板）
- **#9 wide**：壶嘴朝**左前方**，把朝右后方（与 #1 同向，与 #2 不同向）

## 5. 套用规则（如何套用到新产品）

### 5.1 紫砂壶类（默认）

1. **保持 9 张 slot 角色、相机角度、构图、调色锁定不动**
2. **替换产品**：壶型换成客户的新品（西施/秦权/龙蛋…）
3. **替换装饰**：#3 雕花换成新壶的雕花（让用户提供真实雕花图）、#4 刻字换成新壶的刻字（让用户提供真实刻字内容）
4. **替换底款**：#8 用新壶真实的底款印章图（让用户提供），不要 AI 自由编造
5. **保留 UGC 散乱感**：#1 #2 #9 不要做太多道具编排，保持茶友随手拍的克制感

### 5.2 盖碗类（局部调整）

- #5 → 改为「碗沿 macro」：极近距拍碗沿弧线
- #6 → 改为「碗底 macro」：拍碗足 / 圈足
- #7 → 改为「碗盖俯视」：盖钮朝上
- #8 → 改为「碗底款」：盖碗底款通常刻堂号（如「XX 堂制」）
- #3 #4 → 改为「碗身刻花 / 碗身题字」（视用户产品）

### 5.3 公道杯 / 茶杯类（精简）

- 重点保留 #1 #2 #4 #9 即可
- macro slot（#3-#8）可省略或只保留 1-2 张
- 因为公道杯 / 茶杯工艺细节不如紫砂壶丰富

### 5.4 茶宠 / 茶道六君子 / 茶叶罐类（场景优先）

- 重点保留 #1 #9（大场景）+ #6 #8（雕工 / 底款）
- macro slot 大部分可省略
- 因为茶宠 / 茶具配件本身不大，过度 macro 反而不雅

## 10. 实战案例：青蛙莲蓬紫砂壶（2026-08-14 落地 · 方法论定型）

### 10.1 案例背景

产品：青蛙莲蓬紫砂壶（frog lotus Yixing teapot）—— 深紫砂棕主体 + 莲瓣堆塑 + 青绿浮萍带 + 绿色青蛙雕塑钮 + 直筒短嘴 + 耳形把，240ml，无底部印章。装饰特征：壶身中段 10-12 片手工堆塑莲瓣（橙红 → 米黄渐变 + 放射叶脉）、莲瓣下方青绿浮萍带（带棕斑）、盖钮是青蛙雕塑蹲坐在小莲叶上（灵魂卖点）。

### 10.2 v1 → v6 迭代教训（NON-NEGOTIABLE）

| 版本 | 做法 | 结果 | 教训 |
|---|---|---|---|
| v1 | 英文长 prompt 详尽描述产品（壶嘴/莲瓣/青蛙钮/颜色） | ❌ 壶嘴画弯、莲瓣画平 | 文字描述干扰 img2img 对参考图的还原 |
| v2 | 英文 + negative 约束（NOT curved spout / NOT painted petals） | ❌ 仍偏 | 光靠 negative 约束作用有限 |
| **v3** | **中文极简 + 完全不描述产品，image 只传产品图** | ✅ 用户确认 | **让参考图说话：产品细节交给参考图，prompt 只指挥视角/场景/光线/严禁** |
| v4 | v3 基础上 #9 加场景参考图 + 详细场景描述 | ⚠️ 场景对，物体太鲜艳 | 场景图要单独传场景参考 |
| v5 | 换 66_24（低饱和参考图） | ❌ 仍过亮 | 不同光线角度的产品图，色阶差异大 |
| **v6** | 换最暗最沉参考图 + prompt 加「低光/低对比/低饱和/莫兰迪/不要高光」 | ✅ 用户确认 | **色调修正 = 换更准的参考图 + prompt 明确负面色彩约束** |

**核心结论**：img2img 任务里，**参考图才是产品说明书，prompt 只是导演**。文字描述越少，产品还原越准。

### 10.3 核心方法论：v3 参考图驱动（用户验证有效 ✅）

**img2img 任务的正确写法**：

1. **不描述产品** —— 产品外观/壶嘴/莲瓣/盖钮/颜色全部交给参考图（image 参数），prompt 一个字不写
2. **prompt 只指挥 4 件事**：视角构图 / 场景 / 光线氛围 / 严禁项
3. **参考图只用产品图**（不叠加 UGC 风格参考图，避免干扰产品还原）
4. **中文 prompt**，~200 字/张（英文长描述反而干扰产品还原）
5. macro 镜头只写「拍哪个部位 + 占画面多少」，不写部位长什么样

**v3 极简 prompt 模板（每张通用骨架）**：

```text
生成一张 Shopify 茶具{主图/细节特写图/生活场景图}，9:16 竖版，1024×1792。

【产品】以参考图（已作为 image 参数传入）中的紫砂壶为产品主体。直接还原参考图的产品外观、壶嘴方向、把手位置、盖钮姿态、壶身装饰、色彩纹理——产品细节完全以参考图为准，prompt 不再描述任何产品特征。

【场景】
- 产品摆放在圆形深棕色磨砂石茶台（约 25cm 直径）中央
- 茶台置于浅橡木桌面
- 背景墙为冷灰亚光墙（#C8C8C8），无装饰，柔光模糊
- 远景虚化：左上角绿植枝叶 + 右侧深色瓷瓶带干莲蓬

【光线】
- 自然光 + 微暖 2700K-3000K
- 主光从左上 45° 入射
- 浅景深 f/2-2.8，背景虚化为色块
- 柔和阴影

【风格】文人茶室自然光 UGC / 老茶客日常 / Aesop 极简 / 禅意克制

【严禁】
- 不出现手、手腕、人体部位
- 不出现文字、价格、Logo、平台 UI
- 不出现棚拍硬光、玫瑰木暗背景
- 不出现红金礼盒元素
```

### 10.4 色调修正方法论（出图太鲜艳 / 太亮时）

当 img2img 结果「物体太鲜艳 / 整体过亮」（v4 → v6 的实际路径）：

1. **换更暗更沉的产品参考图** —— 用不同光线/角度拍的真实产品图（如 Clipboard 截图），让生图模型看到真实色阶
2. **prompt 加色调负面约束**：
   - 「整体色阶偏低饱和度、莫兰迪/水墨感——不要鲜艳、不要高对比」
   - 「壶身是深紫砂棕（不是亮红棕）」「莲瓣是米黄/淡黄（不是橙红）」「中段带是墨绿/橄榄绿（不是鲜青绿）」
3. **prompt 加光线负面约束**：
   - 「避免强方向光：不要打高光、不要提亮物体边缘、不要让产品发亮」
   - 「光线偏柔光散射，整体亮度中等偏暗，不要过曝」
4. **严禁项追加**：「不出现鲜艳/高饱和/高对比/明亮发光的色调」「不出现强方向光高光、明显的边缘提亮、过曝」

### 10.5 场景图（#9 茶室全景）扩展：生活感版本

当客户想要「家里一角生活感」（而非极简文人茶室）时：

- **image 传 2 张**：`[产品图, 场景布局参考图]`（prompt 里说明哪张是产品、哪张是场景）
- **场景元素清单**（09 UGC 场景参考图的结构）：
  - 厚实高圆柱磨砂石茶台（约 5cm 高，侧面粗砺）
  - 浅蓝 / 浅灰布垫 / 茶席（茶台置于其上，有自然褶皱）
  - 冷灰亚光墙 `#C8C8C8`
  - 远景虚化：木制博古架（带茶具：深色瓷茶壶、小杯、紫砂摆件）+ 绿植
  - 前景清晰：紫砂莲蓬摆件 + 复古小铜盒 / 铁盒
  - 右上角：木质蒸笼 / 带盖茶具
- 产品占画面 25-35%（比 hero 小），多层景深，负空间 65%
- **手持参考图风险**：若产品参考图带手（如手持自拍），prompt 必须强化「参考图里的手不要出现在最终画面中」
